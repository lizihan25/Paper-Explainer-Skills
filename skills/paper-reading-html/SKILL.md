# Paper Reading HTML

让读者快速找到论文的技术贡献，并能沿原图、实验和来源继续深入阅读。

按需要读取一种完整 prompt：

- [精炼版](prompts/concise.md)：默认使用，用目标和阅读效果约束设计。
- [指导版](prompts/guided.md)：需要明确资料组织、页面实现或交互检查顺序时使用。

两版都可单独复制。当前用户要求优先；“个人默认”可随任务替换。页面结构、交互方式与视觉语言由论文和读者需要决定，按需与 `paper-video` 共用资料来源。

分别整理作者在对应版本明列的 Keywords 与 Index Terms，保留原文、来源位置和版本；未列字段与未能核实分开记录。另列研究者扩展的领域检索词，组织中英名、缩写与别名，区分同义、上下位和邻近但不同的概念。核心定义附来源与适用语境，关键词和相关定义连接到对应论文、方法、数据集及资源，支持搜索与双向跳转；具体组织见所选 prompt。

补充近期尚无论文的工作时，可采用成体系的官方项目或 GitHub 仓库，标明材料类型、查询日期、release／commit及公开范围，并区分项目宣称、实验／演示、复现材料与实际复现；热度作为发现线索。

涉及数据集、测试集或评测基准时，按主题设专栏，解释任务、样例、划分、指标、协议与局限，并与实际使用它们的论文实验双向跳转；重要榜单标明赛道和查询日期。选文未使用但领域重要的资源可列为领域补充，具体记录与比较要求见所选 prompt。

涉及模型时，核查总参数与可训练参数、本文训练与推理的资源需求，以及代码、权重、数据、训练／评测脚本和环境分别公开到哪一步。原文、附录、官方仓库与模型卡交叉核对，保留版本、测量条件与查询日期；未报告、供应商未披露和未核实分别说明。具体字段见所选 prompt。

原架构图采用两层导读：图旁保留简短看图提示，展开层沿图中实际标签、区域与箭头解释完整Workflow，讲清输入、表示变化、分支汇合、输出用途及训练／使用的差别。解释术语和易误读处，提供原图放大或对照入口；原文方法与图注共同支撑细节，具体要求见所选 prompt。

检索、补充或替换原图、实验录像、人物照片等素材时，读取已安装的 `paper-assets`，或本仓库的 [素材查找与选择](../paper-assets/SKILL.md)。用素材所解释的问题决定位置与交互；四份制作 prompt 已包含可独立执行的核心要求。

每次构建或增补后，检查最终交付版的首屏加载、长页连续滚动及图文／媒体交互是否流畅。卡顿先定位资源、布局、脚本或媒体开销，再优化并复测；按需加载重资源、管理离屏动画与播放器，保留搜索、锚点、原图可读性及离线阅读。具体方法见所选 prompt，未能实测的范围据实说明。
