# Local Narration

把用户讲稿生成可复用的本地旁白。当前用户要求优先；默认英文、固定合成 F 声线、保持音高的 **1.1 倍**处理。用户已反馈 1.25 倍过快。

按需读取：

- [精炼 prompt](prompts/concise.md)：可独立粘贴给有本地工具的模型。
- [精细指导 GPT prompt](prompts/gpt.md)：包含环境配置、交付与调用方式；适合复制到 GPT 的指令或对话中。
- [环境与音质说明](references/local-environment.md)：首次运行、双引擎比较或排查沙沙感时读取。

## 直接制作

先读取私有配置：`--config` 优先，其次环境变量 `LOCAL_NARRATION_CONFIG`，最后 `config/local.json`。首次使用复制 [配置示例](config/example.json)，填写已有资源路径；所有相对路径以配置文件目录为基准，也支持环境变量与 `~`。公开仓库只保存示例，私有本机路径留在被忽略的 `local.json`。运行 `scripts/narrate.py --resolve-config` 可在不加载模型的情况下检查解析结果，再用配置中的 Python 执行 `--check --engine breeze`。普通任务优先 Breeze，Index 用于指定替代或同文对照。复用已有环境与离线资源；当前脚本的已验证接口与兼容范围见环境说明。

讲稿采用自然连贯的段落，空行分段；独立保存展示原文和发音替换后的文本。每段使用同一份 `assets/reference_F.wav` 及其完整转录，不按句重新设计声音。参考是合成声线，身份来自固定音频，seed 只帮助复现。

默认交付配音与双语字幕。先按 [示例](examples/script-bilingual.json) 准备 `sentences` 数组，每项包含 `en`、`zh` 和所属 `paragraph`。同段英文连贯合成，字幕按短意群切分；中文忠实表达技术含义，保留名称、符号、数字和单位。调用 `scripts/narrate.py --input <双语讲稿.json> --output <新输出目录>`。默认引擎 Breeze、速度 1.1；`--engine index` 选第二引擎，`--speed` 覆盖速度。

输出包含原始/处理后 WAV、拼接旁白、三份 SRT（双语、中文、英文）、中上英下 ASS、实际配置和字幕对齐记录。字幕根据变速后音轨的本地 ASR 词时序对齐，展示原文保持不变；内容或时间不匹配时保留音频与差异记录，修正后再导出。只有用户明确要干声时选 `--audio-only`，此模式也可输入 UTF-8 TXT。BGM 按本次任务另行制作。

先检查漏词、重复、尾句截断和专有名词，再比较段落交界的音色、气声、响度及速度。ASR 可核对内容与时间，听感由实际试听判断。超长段落按完整意思拆开；发生截断时调整分段或容量，保留原始生成结果以便定位。

## 音质与交付

默认无损 WAV、保持音高变速和带峰值约束的固定增益。目标响度允许因峰值余量而降低。需要处理沙沙感时，用同文、同响度的原始/处理后对照查原因，再决定是否重生成或改变处理；去噪、EQ、压缩和动态响度处理按实际需要采用。

提供可播放旁白、双语与单语字幕、原文与发音文本、参考身份、引擎配置和生成结果。字幕默认中文在上、英文在下，检查同步、断句、字号、边距、遮挡及阅读速度；视频尺寸确定后在实际画面中复查。更改音速或剪辑后重做时间轴。有本地执行工具时完成实际生成；只有文件阅读能力的 GPT 输出可交给本地执行器的任务与命令，如实说明尚未在电脑执行的部分。购买服务、上传文本/声音或发布音频沿用具体任务的授权。
