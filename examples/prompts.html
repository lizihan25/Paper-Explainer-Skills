# Paper Video

根据论文的技术特点选择讲法，让观众能沿原图理解信息如何变化，并判断创新和实验结果的意义。

按需要读取一种完整 prompt：

- [精炼版](prompts/concise.md)：默认使用，给模型保留研究、叙事和视觉设计空间。
- [指导版](prompts/guided.md)：需要明确制作顺序、跨阶段衔接或检查重点时使用。

两版都可单独复制。当前用户要求优先；其中“个人默认”来自维护者的观看偏好，可在具体任务中替换。选择技术栈、镜头数量、段落结构和视觉风格时，以论文内容及成品效果为依据。

当前默认顺序为 **机制动画与持续原图定位（新版 A）→ 论文证据导览（早期 C，次优选）→ 纸面自由画布（新版 C）→ 原图显微镜（新版 B）**。用户指定风格时按其要求。早期 C 指 DensePhysNet 的原架构图与实验表导览，不能与 DPI-Net 的 C 自由画布混用；实验结果段优先考虑证据导览，可与 A 的方法机制动画组合。需要认出或比较画风时，读取 [风格索引](references/style-catalog.md)，向用户提供可观看的效果入口。

A 在右上角或合适位置持续保留完整总览图，以平滑移动的红框指示动画对应模块；总览用于定位，关键原图细节另行放大，避免把缩略图当作可读正文。证据导览沿原图解释架构，再结合原始图表讲清实验问题、条件和结果，保留表头、单位、对照与来源。原图显微镜的缩放与平移保持连续，并实际检查运动中的相邻帧。

涉及模型时，核查总参数与可训练参数、本文训练与推理的资源需求，以及代码、权重、数据、训练／评测脚本和环境分别公开到哪一步。原文、附录、官方仓库与模型卡交叉核对，保留版本、测量条件与查询日期；未报告、供应商未披露和未核实分别说明。具体字段见所选 prompt。

检索、补充或替换原图、实验录像、人物照片和声音素材时，读取已安装的 `paper-assets`，或本仓库的 [素材查找与选择](../paper-assets/SKILL.md)。先按知识点选择素材，再确定镜头；四份制作 prompt 已包含可独立执行的核心要求。

# 学术论文视频：精炼 prompt

根据论文及补充材料制作技术讲解视频。结合受众与本次范围自主研究和设计；当前用户要求优先于以下默认。

## 内容

- 讲清研究问题、已有困难及解决思路。简洁介绍论文全名、发表年份与场所、当时的机构/研究组、关键作者及真实照片；查证人物关系，区分预印本与正式发表。
- 沿具体输入讲清“输入信息→各模块的表示变化→输出”，区分训练与推理。关键创新单独展开：改了哪里、为什么有效、相对基线改变什么、实验如何支持。作者主张、论文证据与讲解者评价分别表达，认可或质疑均给出理由。
- 用原始图表和实验片段讲实验问题、比较条件、指标、消融与结果，保留重要失败条件。主线帮助建立联系，时长主要用于技术内容。

## 模型规模与复现资源

核查模型规模、资源与复现条件：分别说明底座、视觉编码器和新增模块，总参数量与实际可训练参数；训练区分底座预训练、本文微调／从头训练及逐场景优化，记录已报告的GPU型号／张数、实测峰值显存（若报告）、时长或GPU小时、步数／epoch与batch。推理单列硬件、精度、输入尺寸／点数、batch、延迟或频率，区分模型前向、规划／重建、网络调用与端到端耗时。开源逐项检查代码、权重、数据、训练／评测脚本和环境，附官方入口及各自许可，区分实际可下载、仅承诺发布、部分发布与闭源API依赖。优先查原文、附录、作者仓库和模型卡；关键数字保留来源与版本日期。未报告、供应商未披露和未核实分别标明；自行计数／估算与作者报告分开，参数量或权重大小不直接代替运行显存，也不据此保证本机性能。视频中讲清影响理解和使用的关键代价，完整资源表随讲稿或阅读资料交付，按技术主线安排篇幅。

## 素材查找与选择

先确定各知识点需要观众看到什么，再沿论文、补充材料、项目页、作者代码与演示查找原图、具体输入和实验录像；人物照片从作者或机构来源核对。关键镜头比较候选，实际查看图片、播放片段，按解释价值、实验与版本匹配、清晰度和构图选用，记录选择理由、来源页码或时间段、裁切与署名要求。保留图例、单位和重要实验条件；素材缺口用有对应关系的重绘或机制动画补足，教学示意与论文结果分别标明。公开可访问不等于可再分发，按发布目标选择使用方式。装有 `paper-assets` 时读取其完整流程。

## 画面

默认顺序：**机制动画＋持续原图定位（新版 A）→ 论文证据导览（早期 C，次优选）→ 纸面自由画布（新版 C）→ 原图显微镜（新版 B）**。早期 C 是 DensePhysNet 的“原架构图＋实验表”证据讲解，与 DPI-Net 的 C 自由画布不同。实验结果段优先考虑证据导览，可与 A 的方法机制动画组合；人类指定风格时优先使用指定方案。忘记选项外观时，先提供[带封面和视频的风格索引](https://lizihan25.github.io/Paper-Explainer-Skills/examples/#style-index)；仓库本地副本的 `examples/index.html` 也可直接打开，按完整风格名选择。

论文证据导览沿原架构图解释关键模块，再回到原始实验图表，把问题、比较条件、指标、消融及结果对应起来。保留表头、单位、对照和来源，逐项高亮后留出阅读时间；主画面承担原图与证据，不用装饰性动画遮挡。

保留原论文图中有用示意。A 在右上角或其他不挤占正文的位置持续放完整总览图，平滑红框随讲解移动到对应模块，主区动画展示具体机制；原图保持到这一技术段结束，留出理解时间，避免只在段首段尾闪现。缩略总览负责位置，需读标签或箭头时在主区放大相应原图。B 用连续镜头平移和缩放导读原图，镜头由绝对时间和固定起止状态计算，保持亚像素采样与段间连续；检查过渡邻帧，修复抖动、突然回缩和错误裁切。

信息流、点流、迭代和静态图难以解释的设计适合插入动画，运动表达具体变化。导航与故事线紧凑、按需出现，正文获得主要面积。多风格试验从空白画布独立设计，共用同一技术内容以便比较。

## 声音与字幕：个人默认

英文配音固定引擎版本、声线或参考音及处理设置，跨段实际试听音色、气声与响度。默认对原始合成音频作一次保持音高的 1.1 倍处理，以自然措辞和停顿形成节奏；复杂图解留出理解时间。中文字幕在上、英文在下，按意群同步。

加入适合技术讲解、许可支持目标发布场景的新轻 BGM，记录来源与署名。旁白时自动压低音乐，关键概念可以留白；实际试听混音和段落接缝。

## 风格与表达

个人偏好可尝试 3Blue1Brown 式黑/中性深灰底、克制的蓝绿黄红语义配色与清晰数学图形，也可探索其他方案。白底原图保留完整图面及颜色含义。

应用 Hypo-Expression：自然、具体地解释对象、动作、条件与因果；删除空泛铺垫、虚构对立和制作自证，保留有用解释。装有 `hypo-exp` 时读取其写作或改稿规则。

## 交付

交付可播放视频、字幕、可修改工程与素材来源。实际查看成片的原图可读性、框选对应、字幕和运动，试听声音一致性及 BGM，修复发现的问题。公开素材按各自许可处理。

# 学术论文视频：指导 prompt

根据提供的论文及相关资料制作技术讲解视频。沿用本次已经明确的受众、范围和交付要求；自主补齐可查证的信息，按论文特点调整下面的制作顺序。文末的个人默认可以替换。

## 1. 找到值得讲透的技术

阅读论文方法、实验、关键图表及相关补充材料。为本次要讲的技术整理一份简短工作稿：

- 研究问题及已有方法遇到的具体困难。
- 一条从实际输入到输出的信息流：每步接收什么、改变什么表示、交给谁；区分训练与推理，明确必要的状态、坐标系或张量含义。
- 关键创新的位置、机制和预期作用，以及能支持或质疑它的基线、消融与结果。
- 对应的原图、页码、实验片段和来源；另记讲解者对价值、代价和适用条件的判断。

能用一个具体例子把关键变化解释清楚后再组织镜头。作者提出的贡献与讲解者认可的贡献可以不同，说明判断依据。

### 模型规模、计算资源与公开范围

涉及模型的论文，整理随片资源卡，片中解释影响理解和复用的核心代价，完整明细放讲稿或阅读资料。先确定所指版本和系统边界：哪些是预训练底座、视觉编码器、新增输出头、逐场景表示、模拟器或外部API；参数规模针对哪个部分，哪些参数实际更新。

- **模型大小：** 总参数、可训练参数及其统计范围；模型变体／版本与权重精度。7B底座的规模不自动代表整个机器人系统。权重下载大小、参数量和运行显存分别记录。
- **训练资源：** 区分底座原始预训练、本文从头训练／微调和逐对象或场景优化。记录原文已报告的GPU型号与张数、硬件标称容量与实测峰值显存（分别标识）、训练时长／GPU小时、batch、步数或epoch及数据规模；API微调和实验搜索成本单列。只在硬件数量与计时范围明确时换算GPU小时，并标明计算依据。
- **推理与部署：** 硬件、精度、输入分辨率／点数／序列长度、batch及延迟／吞吐。模型前向、闭环策略频率、规划搜索、重建、网络请求和完整任务时间分别说明；沿用作者测量条件，不把单步耗时泛化成整个系统实时性。
- **公开与复现：** 分别核查代码、预训练／微调权重、数据、训练与评测脚本、配置和依赖环境；给官方仓库、下载或模型卡入口。标记实际已发布、部分发布、承诺待发布或依赖闭源服务，并核对代码、权重、数据各自许可及访问条件。公共仓库不自动意味着全流程开源。

回到原论文、附录、官方仓库和模型卡补查缺项，保留论文报告与当前发布状态的区别及查询日期。作者未报告、供应商未披露、资料未能核实分别记录；代码推导、实际运行计数或估算单独标注依据和范围。没有实测时保留本机可行性判断为条件，不用参数量、文件大小或峰值GPU配置代替显存与速度测量。

## 2. 查找、比较并选定素材

从工作稿列出各知识点需要观众看到的对象与变化：例如架构位置、真实输入、消息传播、实验对照或作者身份。先沿论文和补充材料的链接寻找原始图表、项目页、作者代码仓库、实验录像与讲解视频；用论文全名、简称和作者名组合检索补足缺项。人物照片以作者、实验室或机构来源核对。

关键镜头有不同候选时，实际查看原图或播放视频，判断哪份素材最能让观众看见当前解释的关系。核对模型版本、实验任务与条件；比较可读性、有效信息面积、视觉焦点、连续性和裁切空间。优先采用信息清楚且与论点直接对应的素材，再通过构图、局部放大和节奏改善观感。保留原图的图例、单位，以及实验的真实/仿真属性、播放速度和重要失败条件。

为选中素材简记“用途—来源位置—选择理由—呈现方式”：来源定位到图号、页码或视频时间段，呈现方式可以是全图、局部裁切、放大、叠加框选或动画。关键候选被舍弃时留一句原因即可。静态素材解释不清变化时，依据论文机制制作动画，并指出其原图位置；教学示意与原始实验结果分别标明。

根据发布目标确认素材的使用条件、署名和保存方式；公开可访问不等于可再分发。BGM 候选与实际旁白混合试听，比较音色、节奏、循环接缝和对语音的遮盖，再选用。素材足以支撑讲解时进入分镜；仍缺什么、影响哪个知识点，具体记录并用合适的来源或示意补足。装有 `paper-assets` 时读取其详细方法。

## 3. 安排内容与身份介绍

用研究问题引入论文，简洁展示全名、发表年份、会议或期刊、当时的机构或研究组，以及关键作者的真实照片和姓名。查证人物关系；年份冲突时区分预印本与正式发表。人物介绍帮助记忆，不打断技术主线。

围绕“为什么需要这项设计→信息怎样变化→变化带来什么结果”组织讲稿。重要创新可以单独成段，用输入变化、基线对照或逐步计算解释。实验部分回答作者在检验什么、改变了什么条件、如何评价、结论由哪些结果支持。把重要失败条件放到对应判断处。

贯穿示例和知识图谱用于建立联系；在章节切换或需要定位时出现。把主要时长留给模型、创新、实验与解释。

## 4. 把原图变成可跟随的讲解

默认顺序为 **机制动画＋持续原图定位（新版 A）→ 论文证据导览（早期 C，次优选）→ 纸面自由画布（新版 C）→ 原图显微镜（新版 B）**。早期 C 来自 DensePhysNet，结合原论文架构图与实验表突出证据；DPI-Net 的 C 是自由画布，两者用完整名称区分。人类指定风格时按指定要求；顺序用于默认选择，无须每次重做所有风格。实验结果段优先考虑证据导览，可与 A 的方法机制动画组合。

需要选风格或用户忘记效果时，提供[可视化风格索引](https://lizihan25.github.io/Paper-Explainer-Skills/examples/#style-index)，让用户直接看封面、用途和视频；本地仓库的 `examples/index.html` 可离线查看。保持各风格名称与样片对应。比较同一批同文样片时可对齐讲解位置；不同论文、语速或时间轴的样片按内容比较，不把相同秒数当作相同知识点。

对每个技术段确定观众正在看哪个区域、讲稿解释哪个变化、下一步关注哪里：

- 全图先建立位置关系；平滑框选、轻度变暗周围或局部放大，把注意移到正在讲的模块。
- 保留原图中的示意、示例和重要箭头。在成片实际尺寸下仍能读到关键内容；密集图采用逐区放大。
- 讲信息流时突出当前输入、变化后的表示及流向，按需要显示数值、维度或几何变化。训练中的梯度路径与推理中的前向路径分别说明。
- A 让机制动画占据主区，在右上角或适合的位置持续保留完整原总览图，红框平滑滑向当前模块。原图跨讲解段持续存在，避免段首段尾短暂闪现；总览作为位置索引，重要标签、箭头和细节另在主区展示清晰原图。给框移动后的目标留出阅读时间。
- 论文证据导览以原图和实验表为主画面：先沿架构定位关键设计，再围绕一个实验问题读图或表。保留表头、单位、比较对象、条件、误差或统计含义；逐行/列突出正在解释的数据，回到作者结论与讲解者判断，给观众辨认和比较的停留时间。必要的机制演示与证据区清楚衔接。
- 当运动比静态图更能解释机制时，用点流、粒子运动、交互、迭代或其他演示。让动画输入、输出、语义颜色与原图对应，红框指示同一部位，再自然推进到下一模块。
- B 的相机根据固定起止位置、尺度和绝对时间计算，在同一原图上连续采样，避免逐帧累乘变换或将浮点裁切反复取整再缩放。下一镜头从上一镜头实际终态开始；同时平移和缩放时检查速度、缓入缓出及停留。
- 导航、知识图谱和故事进度采用紧凑、按需出现的形式。正文和原图拥有主要面积。

## 5. 形成连续的声音与节奏

个人默认是英文配音、中文字幕在上且英文在下。固定引擎与模型版本、声线或克隆参考、采样率及后处理方案，保留能复现的配置。优先按连贯段落生成；专有名词和缩写采用稳定读法。

## 6. 完成成片并检查实际效果

制作范围较大时，先做能覆盖原图导览、一个创新点和实验结果的代表片段，用它修正布局、声音与节奏；在已有授权内继续推进。

查看实际编码后的画面与声音，重点检查原图关键文字、框选部位、动画对应关系、字幕同步、语义颜色、跨段音色和 BGM。连续看技术段之间的衔接，确认观众知道上一段得到什么、下一段为何出现。修改发现的问题后交付视频、字幕、工程及必要的来源说明。

# 文献综述与 HTML：通用精炼 prompt

围绕我给出的主题、论文或研究问题，完成检索、精读、跨论文归纳和 HTML 学习资料。沿用已有受众、用途、时间范围与资源约束；缺少非关键参数时作合理选择并继续。以下是个人默认，当前要求优先。

**逐模型追踪实际信息与应用。** 逐一解释所有实质介绍的模型／方法，包括补充小节与表内方法：实际用了什么信息（如像素／图像特征、点云／几何、潜表示、语言语义、观测或动作历史），学习或辨识什么及显式输出／隐表示／预测／策略等形式，哪些部分在本文训练、冻结调用或逐场景优化，怎样影响后续行动，以及主要应用场景与实际验证的对象、任务、真实／仿真及泛化范围。按论文真实定义说明信息，不必硬套物理信息；有依据时再列物理观测、人工先验、结构／损失约束与模拟条件。正文精炼，细节可展开，跨模型对照并互链；字段随方法调整，不强制长模板或互斥分类。课程、控制基线、传感器与评测工具按自身类型介绍。关键判断附来源，区分作者主张、实验支持、讲解者解释与未验证的泛化。将潜表示解释为质量／摩擦等物性需相应解码、探针实验等明确证据；规律学习、物性恢复与任务成功分别评估。语义常识与经标定的物性估计、权重学习与当前状态更新也分别说明。

**研究从问题开始。** 明确要理解或判断什么、哪些内容纳入、检索截至何时。尤其入门时，与原论文检索并行，优先找优秀综述、领域专家的文献分享／专题报告／阅读清单和高质量大学公开课程，借其分类、术语与参考文献建立候选和学习路线。查看相关内容，比较主题匹配、讲者或课程背景、覆盖范围与年代、所需先修及原文可追溯性；名气和校名作为发现线索。记录所用章节、讲次或时间点，交叉比较不同入口并补查近期方向。沿代表论文追踪前后引用、关键团队的系列工作、并存路线及反例，关键事实回到论文正文、附录、正式论文库或作者材料。用 DOI、arXiv 与题名核对去重，区分预印本、正式发表和修订版本。保存实际检索日期、渠道、检索式、筛选理由和阅读范围；规模由问题覆盖与证据决定，不凑篇数。检索范围与访问缺口决定综述的适用范围。

**关键词与定义也要建立索引。** 分别按原文保存对应版本的作者 Keywords 与 Index Terms，注明来源位置；未列字段与未能核实分开记录。另列研究者扩展的领域检索词，整理中英名、缩写和别名，区分同义、上下位与邻近但不同的概念。核心概念给出有来源的定义及本文语境，定义有差异时按来源并列；用词表帮助检索和理解，支持搜索、就近解释，并与论文、方法、数据集及资源双向关联。

**近期项目补充论文的时效缺口。** 对尚未形成论文的近期进展，可选内容完整的官方项目／GitHub 仓库作为项目材料，记录查询日期、release／commit、公开内容与实验／演示证据；论文结论、项目宣称、有复现材料与实际复现分别表述。热度用于发现候选，入选依据是其与研究问题的关系及可检查的内容。

**数据集与评测也是检索对象。** 按研究主题检索重要数据集、测试集、benchmark 和官方榜单，以原始论文、官方文档和实际采用情况说明入选理由；选文未使用但领域重要的资源也可列为“领域补充”。为各主题设置数据集与评测专栏，介绍任务、数据内容与代表样例、规模和采集方式、真实／仿真属性、版本、训练／验证／测试划分、指标含义及方向、评测协议、获取与许可、适用范围和局限。区分数据资源、测试划分、评测协议与动态榜单；榜单注明赛道、设置和查询日期，排名或分数只在相同协议与条件下比较。论文中的数据集名称链接到专栏，专栏返回关联论文与实验位置，并注明预训练、训练、验证、测试或仅讨论的实际关系；自建数据与公开数据分开记录，未使用的资源保持为领域补充。保留稳定 ID、原始来源与无法查明的字段，无正式榜单时据实说明。

**归纳要解释发展与取舍。** 选出真正值得深入的论文，补齐必要前置知识。沿具体输入说明信息怎样经过各模块变化并产生输出，分清训练和推理；把核心创新拆开讲清，与最近似基线比较，再用实验设计、条件、指标、消融和失败情况检验作者的解释。区分作者主张、原文证据与自己的评价，重要结论就近链接到相应章节、图表或补充材料。跨论文比较先对齐任务、数据和评测条件，保留不可直接比较的部分。

**模型的规模与复现条件也要讲清。** 核查模型规模、资源与复现条件：分别说明底座、视觉编码器和新增模块，总参数量与实际可训练参数；训练区分底座预训练、本文微调／从头训练及逐场景优化，记录已报告的GPU型号／张数、实测峰值显存（若报告）、时长或GPU小时、步数／epoch与batch。推理单列硬件、精度、输入尺寸／点数、batch、延迟或频率，区分模型前向、规划／重建、网络调用与端到端耗时。开源逐项检查代码、权重、数据、训练／评测脚本和环境，附官方入口及各自许可，区分实际可下载、仅承诺发布、部分发布与闭源API依赖。优先查原文、附录、作者仓库和模型卡；关键数字保留来源与版本日期。未报告、供应商未披露和未核实分别标明；自行计数／估算与作者报告分开，参数量或权重大小不直接代替运行显存，也不据此保证本机性能。在论文条目附近呈现，并与资源对照索引双向链接。

**专题资源先就地查看。** 正文的数据／评测专题及模型资源专题入口默认先打开按需浮窗，完整展示主题卡片、来源与论文回链；关闭恢复正文位置和焦点，另设可选的总表主题定位。保留常规链接供无脚本回退及修饰键点击，长内容独立滚动，窄屏可读；只准备当前主题内容，关闭清理临时内容与监听。

**让多篇论文形成关系。** 用问题、思想和证据组织正文，说明路线为什么分支、各自解决什么、为何又能结合。研究发展图标明实际承接或引用关系，教学路线单列概念先修与快读/深读顺序；发表先后、主题相似或课程讲授顺序不等于继承。推荐综述、分享和课程时说明分类视角、覆盖年代、适合读者及遗漏。需要服务项目选题时，再给有基线、实验条件和继续/停止依据的候选路线，保留尚待决定的部分。

**作者卡逐篇可达。** 尽可能为每篇纳入讲解或论文库的论文设置紧凑作者卡，普通点击在按需浮窗查看作者署名、第一作者／共同贡献、通讯作者及发表时机构／研究组；用原文、作者与机构官方资料核对，当前任职另列并标日期。通讯与贡献身份按明确资料标注，不从末位署名推断；仅确认部分信息时列明具体缺项，人物关系附依据。复用真实头像并保留来源和许可，缺照片时仍显示姓名与机构。逐篇核对作者入口覆盖，正文、论文库与人物总表双向关联；浮窗保留来源和可选总表入口，关闭恢复位置、焦点与展开状态，保留常规 href 回退。只准备当前资料，关闭释放临时内容与监听，避免增加滚动负担。

**素材需要寻找和选择。** 从论文、附录、项目页、作者代码与演示中选完整架构图、局部示意、输入输出和真实实验对照；从作者或机构页面核对人物照片。实际查看候选，在讲解尺寸下比较解释价值、版本与条件匹配、可读性和视觉焦点。记录出处、图号或视频片段、裁切方式和使用条件。原图在正文中占有足够面积，用中文导读解释看图顺序；动态机制适合时再补教学动画。重绘保留结构含义并标明教学示意，素材能访问与能再分发分别判断。

**HTML 同时方便快读与深读。** 默认中文，保留英文题名及术语；首屏简洁呈现核心问题、主要认识和阅读入口，完整机制、公式与实验证据可深入展开。正文和主图占主要面积，目录与路线导航紧凑。重点论文介绍全名、发表年份与场所、发表时的研究组和关键作者真实照片，方便记住谁做了什么。照片缺失时仍显示姓名、组别和原始主页。原图支持放大、局部定位和返回全图；讲解步骤对应平滑移动的定位框，保持位置上下文。动画可暂停、重播、分步查看。按内容选择图谱、对照表、筛选或搜索，避免把页面做成只有摘要卡片的资料柜。

逐篇核查原文、附录及补充材料的总览图／Workflow覆盖；已有可用总览图时引入并导读，缺少或不足以解释技术关键时，依据方法、图注与实验材料补教学流程图，明确标注重绘及来源。让输入→关键表示／模块→输出／执行可追踪，区分训练／部署、并行支路、监督与数据流，突出创新。保留必要原图，将补图接入完整Workflow对照；按内容选用清晰、可离线读取的SVG／HTML等形式，支持缩放与宽窄屏阅读，按需加载。

**原图导读要能展开到完整流程。** 原图保留简短导读，并提供可展开的完整Workflow。先说明全图解决什么、从哪里开始看、图例与关键符号；再按原图真实区域和标签，逐步解释每步收到什么、怎样处理、传出什么，以及分支为什么并行、在哪里汇合、回路何时更新。用一个明确标作教学示例的输入串起全过程，分清训练与部署、监督箭头与数据流、模型预测与规划／控制执行。术语就近解释，重点说清最易看错的连接与条件；细节回查论文方法和图注，图中未画出的操作明确说明来源，保留版本与来源定位。展开后仍能方便放大对照原图；详解的深度由理解需要决定。

**放大图时同时读完整Workflow。** 默认采用分栏图文对照（A）：图支持缩放、拖动与返回全图，导读独立滚动，图文比例可调，窄屏上下排列；关闭后恢复原阅读位置、触发点焦点和原有展开状态。另按图记住缩放、平移、图文比例、导读滚动位置和当前步骤，重开同图时恢复。重点架构图可再按解释价值增加步骤平滑定位（C），逐步核对所用原图版本、标签与实际区域，缩放或调整布局后定位仍准确。完整Workflow始终可读，允许跳步与自由浏览全图。由查看器接管图本体拖动，禁用原生图片拖出和意外选中；手动拖动／缩放时暂停自动定位和过渡，提供清楚的手动／跟随或视图锁定控制，锁定只限制自动变化。原图在正文和对照视图直接显示，外链用于追溯；性能优化保留必要原图与清晰细节，教学示意只补充，不能靠删图、替图或强制跳转／另存来减负。按需读取和解码当前图与导读，在打开、缩放、拖动、调整比例或切换步骤期间合并更新，静止和关闭时停止持续更新；实际验证图文对照、状态恢复、定位与流畅度，保留来源及素材许可。

**加载与滚动也要验收。** 把首屏加载与长页滚动流畅度纳入每次构建／增补后的验收：实际打开最终入口，在图、动画与视频密集的代表段落连续滚动、展开和跳转，发现卡顿先定位再优化、复测。图片按展示需要压缩并预留尺寸，首屏关键内容及时加载，其余重资源按需加载；视频点击才创建播放器，收起释放，离屏或后台暂停媒体与动画。滚动更新合并处理，减少重复DOM扫描及交错的布局读写；完整单文件按需解码内嵌图片，在线版可用相对资源懒加载；资源目录／ZIP为可选补充。保留搜索、锚点、全部必要原图的细节和离线能力。记录浏览器、环境与实际检查／测量结果，区分结构检查和流畅度实测；未实测的部分说明限制。

**源码可维护，成品可打开。** Markdown 保存内容、引用和关系，HTML 从它生成。默认交付可独立转发、离线打开的完整单文件HTML，内嵌必要本地原图、照片、样式和脚本；在线版可用相对资源按需加载并保留完整单文件下载，资源目录／ZIP为可选补充。在线材料保留来源、图注和阅读回退。更新时保留有效人物照片、来源与交互。长任务保存研究状态、覆盖缺口、待核查判断和下一步，接续时先读已有记录。使用分工时记录实际阅读与复核范围，不用模型角色名代替真实调用。

自然、具体地解释事实与关系，保留必要深度；删除空泛铺垫、虚构对立、制作自证和无内容的口号。表达遵循 Hypo-Expression；有相应 skill 时使用其写作或改稿操作。

完成后核查核心结论与图，实际在浏览器检查人物照片、图谱/筛选、原图放大、动画控制、来源、键盘与窄屏阅读，并将单文件独立复制到另一目录或设备后断网检查原图与交互。交付主要认识、推荐先读材料及理由、Markdown/HTML/资源入口和影响结论的剩余缺口；研究过程与验证记录保留在制作文件中。

# 文献综述与 HTML：精细指导 prompt

请围绕我给出的主题、论文或研究问题，完成检索、精读、综合和 HTML 学习资料。先读取已有材料与已确认要求，自主推进到可用交付。受众、研究边界、日期范围、输出位置和预算沿用本次任务；普通实现选择由你决定，只有影响结论或范围的关键缺项才集中澄清。以下个人默认可由当前要求替换。

## 1. 确定问题，复用已有研究

说明这份综述要帮助读者理解或判断什么，列出需要覆盖的问题与路线，而后安排检索。记录实际检索日期和截止范围、纳入与排除条件；未知资源条件保持为条件。已有资料库先读索引、Markdown 与研究状态，保留稳定的论文 ID、版本和有效来源，避免重复搜读已经充分支持的内容。

专题研究兼顾奠基思想、关键转折、并存方法和近期变化。材料充分的单一问题可以较早收敛；范围较大时按问题划分精读批次。采用分工时，批量题录和初步摘要、核心原文复核、跨论文综合可分别承担，使用当前可用且获准的模型与工具，记录实际调用、读取范围和复核结果。

## 2. 检索、筛选和补漏

尤其在入门时，将三类学习入口与原论文检索并行安排：优秀综述帮助建立领域分类与代表工作；领域专家的文献分享、专题报告和阅读清单提供问题选择与研究取舍；高质量大学公开课程提供先修概念、讲义和循序学习路径。顺着它们的参考文献寻找候选论文，同时继续既有的关键词与一手来源检索。

实际查看相关章节、讲次或报告片段，比较主题匹配、讲者／课程背景、内容范围、覆盖年代、先修要求和参考文献可追溯性。名气与校名用于发现线索，选用依据是内容怎样帮助本次问题。记录入口来源、所用章节／讲次／时间点、适合的读者与选择理由；将讲者的评价标为其观点，关键机制、实验数字及研究结论回到原论文核对。

交叉比较不同综述、分享与课程的分类和选文，找出共同节点与遗漏路线；对年代较早的入口补查近期进展。再沿代表论文的前向／后向引用、作者系列工作、项目页与官方代码补齐关键节点。保存实际查询与筛选决定。核对 DOI、arXiv、题名和作者进行去重，合并同一研究的版本，保留影响结论的修订差异。

优先精读会进入主要判断、代表路线差别或揭示关键机制的论文。对初步推荐做反向检索，寻找替代方法、失败案例、相反证据或评估设置问题；按覆盖缺口定向补查。检索不到、全文不可得和尚未阅读分别记录。只有摘要的材料可以作为线索，其机制与实验数字待原文支持后再纳入强结论。

保存可继续使用的检索记录：日期、渠道、查询、候选身份与版本、纳入/排除理由、阅读范围和待查项。说明覆盖到哪里、还缺哪条关键路线；综述类型与完整性判断以实际检索方法和覆盖为依据，不以篇数或搜索次数代替。

### 作者关键词、领域检索词与相关定义

把词语作为理解和继续检索的入口，与正文及研究关系一起维护：

- **作者原始字段：** 分别摘录所用版本明列的 Keywords 与 Index Terms，保留原文标签、词条、论文版本和页／节位置；该版本未列、只读范围内未找到与尚未核实分别记录，研究者补充词另列。
- **领域检索词：** 从综述、课程、代表论文及官方资料扩展中英名称、缩写和别名；标明同义、上下位、组成部分或邻近但不同的关系，同名词按语境区分。把检索词实际用于查询与补漏，按新证据修订。
- **定义与边界：** 核心概念就近解释，附原论文、综述、标准或官方文档依据；交代本文的操作性含义与适用条件。不同来源定义不一致时并列说明范围，避免只把英文词换成中文。
- **可用的索引：** Markdown保存词条身份、原始／扩展来源、定义出处与关联ID；HTML让关键词和定义可搜索、可就近查看，并连接对应论文、方法、数据集与资源，再能返回原阅读位置。标签承担真实导航关系，不用只有词频和大小的标签云代替解释。

### 时效性强的项目材料

尚未形成论文的近期进展，可纳入内容完整、与本题有关的官方项目和GitHub仓库；明确它是论文、技术报告、官方项目、代码发布还是演示。记录原始入口、本次查询日期、项目文档日期、可见的release／commit及对应公开范围，分开论文修订与仓库更新。检查任务、接口、实验设置、评测或演示、已公开代码／权重／数据及复现说明；项目宣称、观察到的证据、有复现材料和实际复现分别表述。热度用于发现线索，推荐依据是内容质量、与研究问题的关系和证据；未公开的设置或只有演示的能力保留具体缺项。

### 数据集、评测基准与榜单的并行检索

按本次研究主题，结合综述与代表论文的实验部分、数据集原始论文、维护者文档和官方挑战赛／榜单，筛选重要资源。依据任务代表性、领域实际采用、持续维护或被综述认可的地位说明入选理由；所选论文尚未使用的重要基准也可介绍，标为“领域补充”。覆盖随问题需要决定。

为各主题设置“数据集与评测”专栏，区分数据集、其测试划分、规定任务与协议的 benchmark、以及随提交变化的榜单。每项尽可能说明：

- 名称、简称、稳定 ID、发布者与年份、版本、原始论文和官方数据／代码／评测入口。
- 测什么能力，数据模态、规模与计数单位、采集方式、真实／仿真属性，以及帮助理解的代表样例。
- 训练／验证／测试划分、公开或隐藏测试、跨对象／场景等泛化设置；论文采用的子集或自行重划分单列。
- 指标的含义、单位和优劣方向、评测协议及影响比较的条件；数据偏差、泄漏风险和不能覆盖的能力按证据说明。
- 获取条件、许可和维护状态；榜单额外记录赛道、规则、官方入口与实际查询日期。引用排名或分数时保留对应版本和设置，只在可比条件下比较。

建立论文—资源关系表，标记预训练、训练、验证、测试或仅讨论，并定位到论文实验章节／表格。论文中的资源名称跳到专栏；专栏返回实际使用它的论文与实验位置。选文未使用的补充资源保持独立标识；自建数据也给出定义与可用性，不当作通用公共基准。Markdown 维护稳定 ID、版本与关系，HTML 生成双向链接，同名缩写按来源区分。无法查明的字段注明缺项；没有正式榜单时直接说明，在线榜单离线时保留带日期的说明与来源入口。

## 3. 精读到能够解释技术与实验

重点论文使用一致的事实字段，解释篇幅按贡献安排：

- **身份与问题：** 全名、预印本与正式发表年份/场所、发表时机构或组别、关键作者，以及研究要解决的具体困难。
- **先修与机制：** 读者需要哪些概念；具体输入是什么，经各模块得到什么表示，信息如何交互，输出怎样用于任务；训练与推理分别说明。
- **创新与判断：** 相比最近似基线改变了什么，为什么可能有效；将最有价值的设计单独展开，用实例、原图、必要公式或机制动画帮助理解。
- **实验与证据：** 检验什么假设，数据/任务与设置是什么，哪些条件改变，基线是否公平，指标测量什么；主要结果、消融、泛化和失败条件支持哪些判断。
- **来源与阅读深度：** 关键事实定位到章节、页码、图表或补充材料；记录读到摘要、正文选段、全文或代码的实际范围。有代码、检查代码和实际复现分别记录。

自然区分作者解释、观察到的结果与自己的评价。消融支持特定条件下的解释时保留这些条件；比较跨论文数值前检查任务、数据、硬件、指标与评测协议。遇到冲突回查相关版本与原文，不把未知自动写成方法缺陷。

### 逐模型说明实际信息、学习目标与应用

覆盖正文、补充小节与表内实质介绍的每个模型／方法，按所用版本核对；课程、控制基线、传感器和评测工具按自身类型说明作用。框架以实际使用／学习的信息为准，像素、特征或潜表示无需统一归为物理信息。复用已有条目与来源，字段随方法调整；下列视角可以并存：

- **信息从哪里来：** 按真实定义说明像素／图像特征、点云／几何、潜表示、语言语义、观测或动作历史等，区分原始输入、中间表示与输出。有依据时再说明物理观测、人工给定物性或约束、结构／损失先验、模拟器与随机化条件；记录哪些量已知、被测量或估计、何时可用，输入、监督标签与预测目标分别说明。
- **实际学到／辨识什么：** 依训练目标和输出说明特征、潜表示、显式状态／参数、未来观测／动力学预测或策略等形式，交代监督／奖励依据及可解释范围。预测像素或学习图像特征时按相应目标介绍；只有明确的变量定义与证据才称物性估计或物理规律。已知计算、人工设定和学习结果分别说明。
- **本文更新什么：** 按模块说明从头训练／微调、冻结调用、逐对象或场景优化；同一系统可包含多种方式。分清底座预训练所得与本工作新增能力、权重学习与部署时状态／记忆更新；未训练模型的方法直接说明其估计或调用过程。
- **怎样影响行动：** 追踪这些信息进入哪一处表示、参数或接口，怎样参与候选筛选、规划／模拟、控制参数或直接动作生成。纯感知／离线预测与实际闭环执行分别介绍，未验证的下游用途标作可能应用。
- **用于什么、验证到哪里：** 概括主要场景，再列论文实际测试的任务、对象／材料、机器人或模拟环境及训练／测试条件；用相关指标、消融或泛化实验限定结论。把作者目标、已展示结果与讲解者推断分开，保留未报告或未核实的具体缺项。

正文先简答“用了什么→学到／辨识什么→如何用于行动→在哪验证”，细节就近展开；以可比较的字段做跨模型对照，链接到方法、原图与实验。分类可多标签并随证据调整。以力／触觉为输入只说明利用了该观测；把潜表示具体解释为质量、摩擦等物性，需要相应解码、探针实验等明确证据，缺少这些证据时保留其原始表示含义。物理规律、定量物性恢复与任务成功分别核查；语义常识与经标定的量值估计分别呈现，为机制解释及未验证的泛化标清依据。

### 模型规模、计算资源与公开范围

涉及模型的论文，在对应条目附近提供资源卡，并纳入跨论文比较。先确定所指版本和系统边界：哪些是预训练底座、视觉编码器、新增输出头、逐场景表示、模拟器或外部API；参数规模针对哪个部分，哪些参数实际更新。

- **模型大小：** 总参数、可训练参数及其统计范围；模型变体／版本与权重精度。7B底座的规模不自动代表整个机器人系统。权重下载大小、参数量和运行显存分别记录。
- **训练资源：** 区分底座原始预训练、本文从头训练／微调和逐对象或场景优化。记录原文已报告的GPU型号与张数、硬件标称容量与实测峰值显存（分别标识）、训练时长／GPU小时、batch、步数或epoch及数据规模；API微调和实验搜索成本单列。只在硬件数量与计时范围明确时换算GPU小时，并标明计算依据。
- **推理与部署：** 硬件、精度、输入分辨率／点数／序列长度、batch及延迟／吞吐。模型前向、闭环策略频率、规划搜索、重建、网络请求和完整任务时间分别说明；沿用作者测量条件，不把单步耗时泛化成整个系统实时性。
- **公开与复现：** 分别核查代码、预训练／微调权重、数据、训练与评测脚本、配置和依赖环境；给官方仓库、下载或模型卡入口。标记实际已发布、部分发布、承诺待发布或依赖闭源服务，并核对代码、权重、数据各自许可及访问条件。公共仓库不自动意味着全流程开源。

回到原论文、附录、官方仓库和模型卡补查缺项，保留论文报告与当前发布状态的区别及查询日期。作者未报告、供应商未披露、资料未能核实分别记录；代码推导、实际运行计数或估算单独标注依据和范围。没有实测时保留本机可行性判断为条件，不用参数量、文件大小或峰值GPU配置代替显存与速度测量。

## 4. 综合出研究脉络与学习路线

用问题和思想组织正文。说明哪些困难催生不同路线、关键设计怎样推进问题、什么代价仍然存在，以及新方法如何利用或改变已有思想。主线选有解释价值的节点，其余进入可检索的阅读库；避免逐篇摘要的简单拼接。

按本次用途提供相互区分的关系视图：

- **研究发展图：** 允许分支、合流和多父节点；每条边区分原文明确扩展、方法承接、引用对照或尚待核实，并关联依据。发表先后或主题相似本身不构成继承证据。
- **教学路线：** 从必要概念到适合的课程讲次、综述、专家分享与核心论文，给快速掌握和深入学习入口；先修或讲授顺序是教学安排，研究继承关系另按论文证据确定。
- **项目候选路线：** 仅在任务涉及选题或应用时加入，从已有条件到最小基线、研究缺口和实验设计；交代最相近工作、资源需求、风险及继续/停止依据。排期与选择保持为候选，直至用户决定。

对主要路线做可比较的矩阵：目标、输入先验、表示、学习/推理方式、数据与算力、实验条件、收益和失败情况。分类随证据修订。推荐综述、课程、专家分享与首读论文时说明它们分别帮助读者解决什么问题、从哪一处开始，以及覆盖范围与剩余缺口。

## 5. 寻找素材，再安排页面

围绕每个重要知识点列出素材需求：完整原架构图、局部模块示意、具体输入输出、实验比较、动态过程或人物照片。从论文与补充材料进入项目页、作者代码仓库、报告和原始演示；人物照片从本人、实验室或机构页面查证身份，发表时归属与当前任职分别处理。

实际打开候选图、观看拟用片段及上下文；比较解释作用、论文版本、实验条件、可读性和布局适配。保留图例、坐标轴、单位和比较身份，记录图号/页码/时间段、来源、裁切与选择理由、署名及使用条件。必要时用明确标作教学示意的重绘或动画补足；教学图中的结构、连接和信息方向应依据原文。装有 `paper-assets` 时可使用其完整流程。

原图承担主要结构说明。局部机制讲解保留完整图的定位上下文，定位框平滑移动到相应部分；读者随时可放大或返回全图。静态原图足以说明的部分给予阅读时间，动画用于信息汇聚、迭代、状态变化等确有动态解释价值的地方。

## 6. 制作可快读、可深入的 HTML

个人默认中文正文、英文题名和必要术语。首页用精炼内容呈现主要问题、认识、路线和阅读顺序，保留来源与实质限制；机制和实验解释提供足够深度，按需展开。目录和导航紧凑，正文及重要图像占主要面积。视觉由内容决定，不强制套用既有 PPT 模板。

重点论文在介绍处展示全名、年份、场所、发表时的组别、关键作者与真实照片。人物、论文和贡献互相链接，便于记忆。原图附中文导读、看图顺序和直接来源。论文库按读者需要支持搜索或筛选，图谱节点通向对应论文与证据；交互失效时保留可读正文或列表。

### 逐论文作者卡与作者浮窗

按已纳入正文讲解和论文库的清单逐篇建立作者资料与入口，尽可能覆盖每篇，复用同一人物和组别记录：

- **身份依据：** 保存论文署名及顺序、第一作者、原文明示的共同贡献／通讯作者、发表时机构和研究组；回查对应版本原文、作者或机构官方资料，附来源位置。通讯身份不从末位署名推断；共同署名与导师、负责人等关系分别求证。只有部分信息可确认时显示已确认内容，并列明未核实字段与待查来源。
- **人物与照片：** 当前任职、研究组和去向另列，注明查询日期，与发表时归属分开。尽量复用真实头像，核对身份，保留来源、署名和使用条件；缺照片时保留姓名、机构和主页，不用虚构肖像填补。
- **就近查看：** 正文与论文库提供紧凑作者卡，普通点击按需浮窗展示该篇作者／通讯／团队及来源；人物总表可返回相关论文，浮窗内可选择前往人物总表。保留常规 href、修饰键点击和无脚本阅读路径。长内容独立滚动、窄屏可读；关闭恢复正文位置、焦点和原展开状态，重开保留阅读状态。
- **按需实现：** 只准备当前论文资料和关联人物，复用图片及必要的离线资源；关闭释放临时内容和监听，不增加全书预克隆、常驻轮询或额外滚动扫描。复制内容时维持唯一ID与正确交叉引用。

交付前逐项核对“论文→作者资料→来源／人物总表→相关论文”覆盖，记录实际缺项；实测作者卡、照片、展开、关闭返回、来源、窄屏和离线入口，避免仅有少数代表团队而缺少其他论文的作者入口。

机制动画提供播放、暂停、重播或分步控制；暂停后仍能看懂当前状态。来源尽量定位到页、图或视频片段。若需要组会讲解，再加入有叙事顺序的演示导航与讲稿提示，保留学习模式的完整细节。

Markdown 是内容、引用和关系的维护真源，HTML 从它派生，避免分别修改后漂移。默认交付可独立转发、离线打开的完整单文件HTML，内嵌必要本地论文原图、照片、样式和脚本。在线版可用相对资源按需加载并保留完整单文件下载；资源目录／ZIP作为可选补充，核心正文与原图离线直接可读。在线资源明确标识并保留图注、来源和文字回退；需要服务的交互提供实际可用的启动方法与静态阅读入口。改版时检查已有照片与来源的加载方式，保留有效资源。

### 正文资源入口的就地预览

正文指向数据集／评测专题、模型规模／计算资源／开源范围专题的入口，普通点击先就地查看，保留当前正文：

- **完整主题预览：** 按需浮窗呈现当前主题说明和完整卡片，保留折叠细节、来源及论文回链；长内容独立滚动，窄屏可读。
- **可选的总表定位：** 提供前往数据集总表／模型资源总表并定位当前主题的选项，由读者选择后跳转。关闭恢复正文位置、焦点和原展开状态；保留常规 href，供无脚本回退与修饰键点击。
- **按需准备与清理：** 只准备当前主题内容，关闭清理临时内容和监听；若复制卡片，保持ID与交叉引用正确。

实际检查普通点击未改变正文位置、卡片细节完整可读、关闭恢复、可选总表定位及论文回链；再检查键盘、窄屏、长内容滚动和重复打开／关闭后的清理。

### 总览图覆盖与教学流程图

逐篇判断读者是否能从图中理解方法的技术关键，按实际缺口补图：

- **先找现有总览：** 核查原文、附录和补充材料中的overview／system overview／Workflow及图注，已有可用图时引入并导读，记录图号与版本。不能仅因教材未收录就认定论文没有总览图。
- **按方法补全图解：** 缺图或现有图不足时，依据方法与实验材料重绘教学流程图。连接输入、关键表示／模块、输出和后续执行，分清训练与部署、并行支路、监督与数据流，突出核心设计；只画有依据的模块与连接，布局由论文决定。
- **标明身份与依据：** 图注明“教学流程图／根据原文重绘”，附依据章节、版本和来源；保留理解必需的原图，并说明补图与原图的对应关系。教学图和作者原图分别标识，不把重绘冒充原图。

### 原图的两层Workflow导读

图旁保留简短看图提示，再提供原生可展开的详细导读，让读者能边看原图边理解完整过程：

- **先定位全图：** 说明这张图回答什么问题、输入和输出在哪里、按什么顺序看；解释图例、颜色、符号和箭头的具体含义。区域描述和标签与采用版本的原图对应。
- **逐步追踪信息：** 每步指出图中位置，解释收到的观测／表示／动作是什么，模块怎样处理，输出传到哪里。并行支路说明各自解决什么，汇合时说清拼接、加权、乘法或约束关系；循环指出何时回到哪一步，按需补术语与必要公式。
- **区分阶段和用途：** 训练与部署、条件输入与监督目标、参数学习与当前状态更新、预测与规划／底层控制分别说明。原图省略但理解必需的环节回查正文，并明确属于图外说明。
- **用例与对照：** 用一个标作教学示例的具体输入走完整条路径，保留重要假设；指出读者容易误读的连接或输出含义。支持放大对照原图与返回阅读位置，展开／收起和键盘操作保持可用。

详解以原论文方法、图注和对应版本为依据，不能靠框名猜连接、虚构张量维度或补出作者没有实现的反馈环。首屏保持精炼，展开层保留理解所需的技术深度；检查每步都能对应原图，示例与真实实验分别标识。

### 放大时的图文对照与步骤定位

先实现默认的分栏图文对照（A），重点架构图可再按解释价值补充步骤定位（C）：

- **同时阅读图文：** 论文原图在正文和放大对照中直接显示，与完整Workflow同时可读；来源链接用于追溯。图支持缩放、拖动与返回全图，导读独立滚动；用分隔条或清楚的控件调节图文比例，窄屏上下排列。保留图注、来源和原有素材许可信息。
- **保留阅读状态：** 从原图或导读进入时，保存原阅读位置、触发点焦点及相关展开状态；关闭后恢复这些状态。另按图保存缩放、平移、图文比例、导读滚动位置和当前步骤，再次打开同图时恢复。完整Workflow始终可读，读者可以跳到任一步，也可以自由查看整张图。
- **可选的步骤平滑定位（C）：** 将步骤绑定到所用原图版本的实际区域，逐步核对标签、分支、裁切和区域位置。框随步骤平滑移动，缩放、拖动或调整比例后仍指向同一区域；提供返回全图入口。步骤说明连接完整Workflow，阅读顺序由读者选择。
- **手动查看优先：** 查看器接管图本体的指针拖动，禁用浏览器原生图片拖出和意外文本选中。手动拖动／缩放时中止未完成的定位过渡并暂停自动定位，结束后保持手动视图；提供清楚的手动／跟随或视图锁定控制。锁定只限制自动视图变化，手动平移、缩放和返回全图仍可用。
- **按需工作：** 保留所有必要原图和可读细节，教学示意用于补充；性能优化不能靠删图、替图或强制跳转／另存。按需读取、解码当前图与导读，打开、缩放、拖动、调整比例和切换步骤时合并必要更新；静止、关闭或后台时停止持续的图框更新，避免为所有图片同时构建副本或循环扫描整页。沿用后文的性能检查，保留搜索、锚点与离线阅读。
- **实际验证：** 在宽屏和窄屏中打开有完整导读的代表图，从图本体实际拖拽，确认图随指针平移且没有原生拖出预览；分别在步骤定位过渡中和结束后测试手动查看与锁定控制。一边缩放／拖动图，一边滚动读完Workflow，并调节比例。分别从展开与收起状态进入，关闭后核对阅读位置、焦点及展开状态；再次打开同图，核对缩放、平移、图文比例、导读滚动位置和当前步骤均已恢复；检查键盘操作。若启用步骤定位，逐步检查框与原图对应，并在变换和布局调整后复查。重复打开／关闭并检查静止时开销，记录实际结果及未测限制。

## 7. 核查、接续与交付

核对主要判断、关键数字、原图身份和图谱关系，检查 Markdown 与 HTML 是否一致；不同角色的复核范围据实记录。实际在浏览器打开首页及代表性精读页，检查人物照片、图放大与定位、搜索/筛选、节点、动画控制、来源、键盘和窄屏。将单文件独立复制到另一目录或设备后断网重开，检查原图、本地资源和交互；若另交资源包，再检查迁移或解压后的相对路径。记录真正执行的检查与影响使用的剩余问题。

### 构建后的加载与滚动性能

每次构建或内容增补后，将流畅度作为交付检查的一部分，先做代表性实测，有问题再深入定位：

- **实际阅读：** 打开最终交付入口，观察首次加载，在图、动画和视频较多的长段落连续上下滚动，并试展开／收起、章节跳转、搜索和原图放大。按实际交付范围检查本地包与线上版，区分冷加载与缓存后的表现。
- **定位开销：** 出现明显卡顿时，结合浏览器性能或网络记录区分脚本、布局、绘制、资源解码、媒体和网络开销；页面字节数与滚动流畅度分别判断，按定位结果选择修改。
- **控制资源加载：** 图片按展示尺寸优化、预留宽高并保留可读的原图入口；首屏关键内容及时加载，非首屏重资源按需加载。视频先呈现封面与播放入口，点击后才创建播放器，收起或关闭后释放。单文件保留完整内嵌资源，重图按需解码；在线版可用相对资源懒加载。优化保留必要论文大图与细节，分别观察下载体积、解码和滚动开销。
- **管理持续工作：** 滚动与窗口变化时合并必要更新，减少重复全页扫描和交错布局读写；按动画帧批量更新或按需节流。离屏、折叠及后台动画／媒体暂停或不启动，返回时遵循用户的暂停与播放状态。
- **复测与记录：** 优化后在相同条件下复测，核对搜索、锚点、原图细节及离线阅读仍可用。记录设备／浏览器、测试入口、实际观察与测量、修复结果及剩余限制；结构检查、资源压缩结果和流畅度实测分别报告，无法实测的部分据实说明。

### 内容与交付核查

对照正文、补充小节及表内方法清单，逐项检查实际使用／学习的信息、更新对象、行动用途与应用场景的覆盖；抽查像素、点云、潜表示等是否沿用真实定义，物性／规律解释是否有相应证据，以及显式／隐式、训练／冻结／逐场景优化和实验范围的区分。确认主文简答、展开细节和跨模型对照一致，未把控制基线或评测工具列作新模型。

抽查作者关键词／Index Terms与扩展检索词的标识、定义出处和语境，检查关键词索引、正文、方法及资源之间的搜索与双向跳转。

## 模型实际使用／学习的信息与应用场景

逐一解释所有实质介绍的模型／方法，包括补充小节与表内方法：实际用了什么信息（如像素／图像特征、点云／几何、潜表示、语言语义、观测或动作历史），学习或辨识什么及显式输出／隐表示／预测／策略等形式，哪些部分在本文训练、冻结调用或逐场景优化，怎样影响后续行动，以及主要应用场景与实际验证的对象、任务、真实／仿真及泛化范围。按论文真实定义说明信息，不必硬套物理信息；有依据时再列物理观测、人工先验、结构／损失约束与模拟条件。正文精炼，细节可展开，跨模型对照并互链；字段随方法调整，不强制长模板或互斥分类。课程、控制基线、传感器与评测工具按自身类型介绍。关键判断附来源，区分作者主张、实验支持、讲解者解释与未验证的泛化。将潜表示解释为质量／摩擦等物性需相应解码、探针实验等明确证据；规律学习、物性恢复与任务成功分别评估。语义常识与经标定的物性估计、权重学习与当前状态更新也分别说明。

## 模型规模与复现资源

## 身份与记忆

逐篇核查原文、附录及补充材料的总览图／Workflow覆盖；已有可用总览图时引入并导读，缺少或不足以解释技术关键时，依据方法、图注与实验材料补教学流程图，明确标注重绘及来源。让输入→关键表示／模块→输出／执行可追踪，区分训练／部署、并行支路、监督与数据流，突出创新。保留必要原图，将补图接入完整Workflow对照；按内容选用清晰、可离线读取的SVG／HTML等形式，支持缩放与宽窄屏阅读，按需加载。

原图保留简短导读，并提供可展开的完整Workflow。先说明全图解决什么、从哪里开始看、图例与关键符号；再按原图真实区域和标签，逐步解释每步收到什么、怎样处理、传出什么，以及分支为什么并行、在哪里汇合、回路何时更新。用一个明确标作教学示例的输入串起全过程，分清训练与部署、监督箭头与数据流、模型预测与规划／控制执行。术语就近解释，重点说清最易看错的连接与条件；细节回查论文方法和图注，图中未画出的操作明确说明来源，保留版本与来源定位。展开后仍能方便放大对照原图；详解的深度由理解需要决定。

放大图时同时呈现完整Workflow。默认采用分栏图文对照（A）：图支持缩放、拖动与返回全图，导读独立滚动，图文比例可调，窄屏上下排列；关闭后恢复原阅读位置、触发点焦点和原有展开状态。另按图记住缩放、平移、图文比例、导读滚动位置和当前步骤，重开同图时恢复。重点架构图可再按解释价值增加步骤平滑定位（C），逐步核对所用原图版本、标签与实际区域，缩放或调整布局后定位仍准确。完整Workflow始终可读，允许跳步与自由浏览全图。由查看器接管图本体拖动，禁用原生图片拖出和意外选中；手动拖动／缩放时暂停自动定位和过渡，提供清楚的手动／跟随或视图锁定控制，锁定只限制自动变化。原图在正文和对照视图直接显示，外链用于追溯；性能优化保留必要原图与清晰细节，教学示意只补充，不能靠删图、替图或强制跳转／另存来减负。按需读取和解码当前图与导读，在打开、缩放、拖动、调整比例或切换步骤期间合并更新，静止和关闭时停止持续更新；实际验证图文对照、状态恢复、定位与流畅度，保留来源及素材许可。

## 加载与滚动性能

把首屏加载与长页滚动流畅度纳入每次构建／增补后的验收：实际打开最终入口，在图、动画与视频密集的代表段落连续滚动、展开和跳转，发现卡顿先定位再优化、复测。图片按展示需要压缩并预留尺寸，首屏关键内容及时加载，其余重资源按需加载；视频点击才创建播放器，收起释放，离屏或后台暂停媒体与动画。滚动更新合并处理，减少重复DOM扫描及交错的布局读写；完整单文件按需解码内嵌图片，在线版可用相对资源懒加载；资源目录／ZIP为可选补充。保留搜索、锚点、全部必要原图的细节和离线能力。记录浏览器、环境与实际检查／测量结果，区分结构检查和流畅度实测；未实测的部分说明限制。

## 交付与素材

个人默认：中文讲解，保留英文题名和术语，交付可独立转发、离线打开的完整单文件HTML，内嵌必要本地原图、真实人物照片、样式及脚本。在线版可用相对资源按需加载，并保留完整单文件下载；资源目录／ZIP为可选补充。在线来源入口另行标明。记录来源，公开发布遵循素材许可；缺图时说明具体缺项并继续查找。

视觉方案由内容决定，可独立探索浅色学术阅读、中性黑底图解等方向。改版保留有效的人物照片、来源与阅读功能。

## 表达与完成标准

应用 Hypo-Expression：自然、具体地解释事实与关系，删除空泛铺垫、虚构对立和制作自证，保留有用解释。装有 `hypo-exp` 时读取其写作或改稿规则。

交付 HTML、资源与可修改源码。实际打开检查身份与图片、内容展开、原图定位和来源跳转；将单文件独立复制到另一目录或设备后离线复查原图和本地资源，在不同屏幕宽度检查阅读、键盘操作及交互，修复问题。

# 学术论文 HTML：指导 prompt

根据提供的论文与补充材料制作 HTML 阅读资料。沿用本次明确的受众、内容范围和交付方式，主动补齐可查的信息。根据材料调整下面的过程；个人默认允许替换。

## 1. 整理论文、人物与技术依据

围绕读者要理解的问题阅读方法、实验和关键图表，并整理：

- 论文全名、正式发表年份与场所、必要时单列的预印本年份、发表时的机构或研究组。
- 帮助记忆的关键作者、真实照片、姓名与团队关系；使用作者、实验室或机构的可靠来源核对身份。
- 研究问题、核心思路、具体输入、模块间表示变化和输出，分别说明训练与推理。
- 关键创新的位置、机制、基线与消融依据；记录讲解者的评价及其理由。
- 相关原图、示意、实验片段与来源页码，以及实验条件、指标和重要结果。

人员与机构关系按论文发表时的情况介绍；当前去向只有与阅读目的有关时补充。作者论述、实验发现与讲解者判断在组织内容时保持清楚。

### 作者关键词、领域检索词与相关定义

把词语作为理解和继续检索的入口，与正文及研究关系一起维护：

- **作者原始字段：** 分别摘录所用版本明列的 Keywords 与 Index Terms，保留原文标签、词条、论文版本和页／节位置；该版本未列、只读范围内未找到与尚未核实分别记录，研究者补充词另列。
- **领域检索词：** 从综述、课程、代表论文及官方资料扩展中英名称、缩写和别名；标明同义、上下位、组成部分或邻近但不同的关系，同名词按语境区分。把检索词实际用于查询与补漏，按新证据修订。
- **定义与边界：** 核心概念就近解释，附原论文、综述、标准或官方文档依据；交代本文的操作性含义与适用条件。不同来源定义不一致时并列说明范围，避免只把英文词换成中文。
- **可用的索引：** Markdown保存词条身份、原始／扩展来源、定义出处与关联ID；HTML让关键词和定义可搜索、可就近查看，并连接对应论文、方法、数据集与资源，再能返回原阅读位置。标签承担真实导航关系，不用只有词频和大小的标签云代替解释。

### 时效性强的项目材料

尚未形成论文的近期进展，可纳入内容完整、与本题有关的官方项目和GitHub仓库；明确它是论文、技术报告、官方项目、代码发布还是演示。记录原始入口、本次查询日期、项目文档日期、可见的release／commit及对应公开范围，分开论文修订与仓库更新。检查任务、接口、实验设置、评测或演示、已公开代码／权重／数据及复现说明；项目宣称、观察到的证据、有复现材料和实际复现分别表述。热度用于发现线索，推荐依据是内容质量、与研究问题的关系和证据；未公开的设置或只有演示的能力保留具体缺项。

### 按主题组织数据集与评测

从论文实验与补充材料、数据集原始论文、维护者文档、相关综述和官方挑战赛／榜单，检索重要数据集、测试集及 benchmark。按研究问题分主题设专栏，依据任务代表性、实际采用或综述认可说明入选理由；领域重要但选文未使用的资源标为“领域补充”。区分数据集本体、测试划分、评测协议和动态榜单。

每项介绍名称／简称、稳定 ID、发布者与年份、版本及官方来源；说明测什么、数据模态、规模与计数单位、采集方式、真实／仿真属性，并用代表样例帮助理解。交代训练／验证／测试、公开／隐藏测试、跨对象或场景划分、论文使用的子集与重划分；解释指标含义、单位、优劣方向、评测协议、获取和许可，以及有证据支持的偏差、泄漏风险与能力局限。自建数据说明定义和可用性；字段缺失时保留具体缺项。

记录每篇论文与资源的实际关系：预训练、训练、验证、测试或仅讨论，定位到实验章节／表格。论文中的资源名称链接到专栏，专栏提供返回关联论文及实验位置的入口；补充资源不建立虚假的使用关系。Markdown 保存资源版本、稳定 ID 与关系，HTML 从它生成链接，同名缩写按来源区分。榜单记录官方入口、赛道、规则、设置与查询日期；引用名次和分数保留对应版本，只在可比条件下比较。没有正式榜单时直接说明；离线保留带日期的介绍，将在线榜单单独标识。

### 逐模型说明实际信息、学习目标与应用

覆盖正文、补充小节与表内实质介绍的每个模型／方法，按所用版本核对；课程、控制基线、传感器和评测工具按自身类型说明作用。框架以实际使用／学习的信息为准，像素、特征或潜表示无需统一归为物理信息。复用已有条目与来源，字段随方法调整；下列视角可以并存：

- **信息从哪里来：** 按真实定义说明像素／图像特征、点云／几何、潜表示、语言语义、观测或动作历史等，区分原始输入、中间表示与输出。有依据时再说明物理观测、人工给定物性或约束、结构／损失先验、模拟器与随机化条件；记录哪些量已知、被测量或估计、何时可用，输入、监督标签与预测目标分别说明。
- **实际学到／辨识什么：** 依训练目标和输出说明特征、潜表示、显式状态／参数、未来观测／动力学预测或策略等形式，交代监督／奖励依据及可解释范围。预测像素或学习图像特征时按相应目标介绍；只有明确的变量定义与证据才称物性估计或物理规律。已知计算、人工设定和学习结果分别说明。
- **本文更新什么：** 按模块说明从头训练／微调、冻结调用、逐对象或场景优化；同一系统可包含多种方式。分清底座预训练所得与本工作新增能力、权重学习与部署时状态／记忆更新；未训练模型的方法直接说明其估计或调用过程。
- **怎样影响行动：** 追踪这些信息进入哪一处表示、参数或接口，怎样参与候选筛选、规划／模拟、控制参数或直接动作生成。纯感知／离线预测与实际闭环执行分别介绍，未验证的下游用途标作可能应用。
- **用于什么、验证到哪里：** 概括主要场景，再列论文实际测试的任务、对象／材料、机器人或模拟环境及训练／测试条件；用相关指标、消融或泛化实验限定结论。把作者目标、已展示结果与讲解者推断分开，保留未报告或未核实的具体缺项。

正文先简答“用了什么→学到／辨识什么→如何用于行动→在哪验证”，细节就近展开；以可比较的字段做跨模型对照，链接到方法、原图与实验。分类可多标签并随证据调整。以力／触觉为输入只说明利用了该观测；把潜表示具体解释为质量、摩擦等物性，需要相应解码、探针实验等明确证据，缺少这些证据时保留其原始表示含义。物理规律、定量物性恢复与任务成功分别核查；语义常识与经标定的量值估计分别呈现，为机制解释及未验证的泛化标清依据。

### 模型规模、计算资源与公开范围

涉及模型的论文，在对应条目附近提供资源卡，并纳入跨论文比较。先确定所指版本和系统边界：哪些是预训练底座、视觉编码器、新增输出头、逐场景表示、模拟器或外部API；参数规模针对哪个部分，哪些参数实际更新。

- **模型大小：** 总参数、可训练参数及其统计范围；模型变体／版本与权重精度。7B底座的规模不自动代表整个机器人系统。权重下载大小、参数量和运行显存分别记录。
- **训练资源：** 区分底座原始预训练、本文从头训练／微调和逐对象或场景优化。记录原文已报告的GPU型号与张数、硬件标称容量与实测峰值显存（分别标识）、训练时长／GPU小时、batch、步数或epoch及数据规模；API微调和实验搜索成本单列。只在硬件数量与计时范围明确时换算GPU小时，并标明计算依据。
- **推理与部署：** 硬件、精度、输入分辨率／点数／序列长度、batch及延迟／吞吐。模型前向、闭环策略频率、规划搜索、重建、网络请求和完整任务时间分别说明；沿用作者测量条件，不把单步耗时泛化成整个系统实时性。
- **公开与复现：** 分别核查代码、预训练／微调权重、数据、训练与评测脚本、配置和依赖环境；给官方仓库、下载或模型卡入口。标记实际已发布、部分发布、承诺待发布或依赖闭源服务，并核对代码、权重、数据各自许可及访问条件。公共仓库不自动意味着全流程开源。

回到原论文、附录、官方仓库和模型卡补查缺项，保留论文报告与当前发布状态的区别及查询日期。作者未报告、供应商未披露、资料未能核实分别记录；代码推导、实际运行计数或估算单独标注依据和范围。没有实测时保留本机可行性判断为条件，不用参数量、文件大小或峰值GPU配置代替显存与速度测量。

## 2. 查找并选择能解释问题的素材

按知识点确定需要什么：模型原图、具体输入样例、关键实验对照、动态过程或作者照片。先检查论文及补充材料，再沿项目页、作者代码仓库和实验演示寻找原始素材；用论文全名、简称与作者名检索尚缺的部分。人物照片从作者、实验室或机构来源核对身份。

关键配图比较候选并查看实际内容，视频播放相关片段。选择能清楚呈现当前机制或证据的版本，核对论文版本、实验任务、条件和图注；再比较文字可读性、有效信息面积、视觉焦点与布局适配。保留图例、单位和重要条件。录像中的真实/仿真属性和变速信息应能被读者识别。

用简短清单记录用途、来源页码/图号/视频时间段、选择理由、局部裁切或交互方式、使用条件和本地文件。机制图适合分步定位，实验对照适合并排查看，动态过程适合带控制的片段；静态图解释不清的部分可用有论文依据的重绘或动画补足，并标明教学示意。重要落选素材只需记下舍弃原因，不追求素材数量。

结合目标发布方式决定随包保存、采用可再分发替代素材或提供来源链接。技术内容充分后进入页面组织；关键缺项注明影响并继续查找，避免用不对应的装饰图填补。装有 `paper-assets` 时读取其完整流程。

## 3. 设计能够快读与深读的页面

让读者先看到研究问题、关键贡献和重要结果，再按兴趣继续深入。可以用简短摘要、图注、并列对照和展开区组织信息；完整机制解释保留连贯段落，页面结构由内容决定。

在论文介绍位置放身份卡：全名、年份、发表场所、研究组、关键作者及照片。多人或多论文时按需要关联同一人物、组别和研究路线。人物信息与技术内容互相指向，帮助回忆“谁在何时做了什么”。

### 逐论文作者卡与作者浮窗

按已纳入正文讲解和论文库的清单逐篇建立作者资料与入口，尽可能覆盖每篇，复用同一人物和组别记录：

- **身份依据：** 保存论文署名及顺序、第一作者、原文明示的共同贡献／通讯作者、发表时机构和研究组；回查对应版本原文、作者或机构官方资料，附来源位置。通讯身份不从末位署名推断；共同署名与导师、负责人等关系分别求证。只有部分信息可确认时显示已确认内容，并列明未核实字段与待查来源。
- **人物与照片：** 当前任职、研究组和去向另列，注明查询日期，与发表时归属分开。尽量复用真实头像，核对身份，保留来源、署名和使用条件；缺照片时保留姓名、机构和主页，不用虚构肖像填补。
- **就近查看：** 正文与论文库提供紧凑作者卡，普通点击按需浮窗展示该篇作者／通讯／团队及来源；人物总表可返回相关论文，浮窗内可选择前往人物总表。保留常规 href、修饰键点击和无脚本阅读路径。长内容独立滚动、窄屏可读；关闭恢复正文位置、焦点和原展开状态，重开保留阅读状态。
- **按需实现：** 只准备当前论文资料和关联人物，复用图片及必要的离线资源；关闭释放临时内容和监听，不增加全书预克隆、常驻轮询或额外滚动扫描。复制内容时维持唯一ID与正确交叉引用。

交付前逐项核对“论文→作者资料→来源／人物总表→相关论文”覆盖，记录实际缺项；实测作者卡、照片、展开、关闭返回、来源、窄屏和离线入口，避免仅有少数代表团队而缺少其他论文的作者入口。

为核心方法安排一条可跟随的信息流。用真实或明确标作示意的输入解释每一步得到什么表示、为什么要这样变化，以及最终如何用于任务。选择最值得理解的创新单独展开，解释它相对基线改变了什么，再接对应实验。

实验部分帮助读者判断设计：研究者检验什么、改变了哪些条件、与谁比较、指标测量什么、结果支持什么判断。重要失败条件放在对应结果旁边。目录和路线图保持紧凑，正文与原图占主要面积。

## 4. 用原图与交互帮助理解

原图、原始示意和实验片段放在相关解释附近，提供可读的图注、来源和放大方式。密集架构图采用全图定位、平滑框选与局部放大；步骤切换时明确指出当前讲解在原图的哪个部位，并保留返回全图的入口。

交互按理解需要添加：信息流可逐步查看，点流或迭代可播放、暂停和重播，图表可对照关键条件。提供足够的静态说明，让暂停动画后仍能理解当前状态。

来源链接通向实际论文、项目页或补充材料，能定位时跳到对应页、图或视频片段。区分本地资料与在线入口。页面中的按钮、目录和展开区使用清楚名称，键盘操作与小屏幕阅读保持可用。

### 正文资源入口的就地预览

正文指向数据集／评测专题、模型规模／计算资源／开源范围专题的入口，普通点击先就地查看，保留当前正文：

- **完整主题预览：** 按需浮窗呈现当前主题说明和完整卡片，保留折叠细节、来源及论文回链；长内容独立滚动，窄屏可读。
- **可选的总表定位：** 提供前往数据集总表／模型资源总表并定位当前主题的选项，由读者选择后跳转。关闭恢复正文位置、焦点和原展开状态；保留常规 href，供无脚本回退与修饰键点击。
- **按需准备与清理：** 只准备当前主题内容，关闭清理临时内容和监听；若复制卡片，保持ID与交叉引用正确。

实际检查普通点击未改变正文位置、卡片细节完整可读、关闭恢复、可选总表定位及论文回链；再检查键盘、窄屏、长内容滚动和重复打开／关闭后的清理。

### 总览图覆盖与教学流程图

逐篇判断读者是否能从图中理解方法的技术关键，按实际缺口补图：

- **先找现有总览：** 核查原文、附录和补充材料中的overview／system overview／Workflow及图注，已有可用图时引入并导读，记录图号与版本。不能仅因教材未收录就认定论文没有总览图。
- **按方法补全图解：** 缺图或现有图不足时，依据方法与实验材料重绘教学流程图。连接输入、关键表示／模块、输出和后续执行，分清训练与部署、并行支路、监督与数据流，突出核心设计；只画有依据的模块与连接，布局由论文决定。
- **标明身份与依据：** 图注明“教学流程图／根据原文重绘”，附依据章节、版本和来源；保留理解必需的原图，并说明补图与原图的对应关系。教学图和作者原图分别标识，不把重绘冒充原图。
- **接入阅读与验收：** 将补图与完整Workflow放入既有同屏对照，图文标签和步骤一致；按内容选SVG／HTML等清晰、轻量且可离线读取的形式。检查箭头语义、关键分支和阶段边界，实际验证缩放、宽窄屏可读性、返回位置与单文件资源；沿用下文的按需加载与性能检查。

### 原图的两层Workflow导读

图旁保留简短看图提示，再提供原生可展开的详细导读，让读者能边看原图边理解完整过程：

- **先定位全图：** 说明这张图回答什么问题、输入和输出在哪里、按什么顺序看；解释图例、颜色、符号和箭头的具体含义。区域描述和标签与采用版本的原图对应。
- **逐步追踪信息：** 每步指出图中位置，解释收到的观测／表示／动作是什么，模块怎样处理，输出传到哪里。并行支路说明各自解决什么，汇合时说清拼接、加权、乘法或约束关系；循环指出何时回到哪一步，按需补术语与必要公式。
- **区分阶段和用途：** 训练与部署、条件输入与监督目标、参数学习与当前状态更新、预测与规划／底层控制分别说明。原图省略但理解必需的环节回查正文，并明确属于图外说明。
- **用例与对照：** 用一个标作教学示例的具体输入走完整条路径，保留重要假设；指出读者容易误读的连接或输出含义。支持放大对照原图与返回阅读位置，展开／收起和键盘操作保持可用。

详解以原论文方法、图注和对应版本为依据，不能靠框名猜连接、虚构张量维度或补出作者没有实现的反馈环。首屏保持精炼，展开层保留理解所需的技术深度；检查每步都能对应原图，示例与真实实验分别标识。

### 放大时的图文对照与步骤定位

先实现默认的分栏图文对照（A），重点架构图可再按解释价值补充步骤定位（C）：

- **同时阅读图文：** 论文原图在正文和放大对照中直接显示，与完整Workflow同时可读；来源链接用于追溯。图支持缩放、拖动与返回全图，导读独立滚动；用分隔条或清楚的控件调节图文比例，窄屏上下排列。保留图注、来源和原有素材许可信息。
- **保留阅读状态：** 从原图或导读进入时，保存原阅读位置、触发点焦点及相关展开状态；关闭后恢复这些状态。另按图保存缩放、平移、图文比例、导读滚动位置和当前步骤，再次打开同图时恢复。完整Workflow始终可读，读者可以跳到任一步，也可以自由查看整张图。
- **可选的步骤平滑定位（C）：** 将步骤绑定到所用原图版本的实际区域，逐步核对标签、分支、裁切和区域位置。框随步骤平滑移动，缩放、拖动或调整比例后仍指向同一区域；提供返回全图入口。步骤说明连接完整Workflow，阅读顺序由读者选择。
- **手动查看优先：** 查看器接管图本体的指针拖动，禁用浏览器原生图片拖出和意外文本选中。手动拖动／缩放时中止未完成的定位过渡并暂停自动定位，结束后保持手动视图；提供清楚的手动／跟随或视图锁定控制。锁定只限制自动视图变化，手动平移、缩放和返回全图仍可用。
- **按需工作：** 保留所有必要原图和可读细节，教学示意用于补充；性能优化不能靠删图、替图或强制跳转／另存。按需读取、解码当前图与导读，打开、缩放、拖动、调整比例和切换步骤时合并必要更新；静止、关闭或后台时停止持续的图框更新，避免为所有图片同时构建副本或循环扫描整页。沿用后文的性能检查，保留搜索、锚点与离线阅读。
- **实际验证：** 在宽屏和窄屏中打开有完整导读的代表图，从图本体实际拖拽，确认图随指针平移且没有原生拖出预览；分别在步骤定位过渡中和结束后测试手动查看与锁定控制。一边缩放／拖动图，一边滚动读完Workflow，并调节比例。分别从展开与收起状态进入，关闭后核对阅读位置、焦点及展开状态；再次打开同图，核对缩放、平移、图文比例、导读滚动位置和当前步骤均已恢复；检查键盘操作。若启用步骤定位，逐步检查框与原图对应，并在变换和布局调整后复查。重复打开／关闭并检查静止时开销，记录实际结果及未测限制。

## 5. 保持人物照片与本地资源可用

个人默认交付可独立转发、离线打开的完整单文件HTML：正文中文，保留英文论文题名及关键术语，将必要本地论文原图、真实人物照片、样式与脚本内嵌。在线版可用相对资源按需加载，并保留完整单文件下载；资源目录／ZIP作为可选补充。重要原图与内容在离线时仍直接可读。

记录素材来源和公开发布所需的许可或署名。需要限制再分发的素材，按目标发布方式安排链接、替代素材或随包获取方式，并明确哪些内容需要联网。暂时缺少照片时保留姓名、组别和来源，说明具体缺项并继续查找。

修改已有 HTML 时，先了解照片、来源与交互的当前实现，查明缺失原因后修复。重构完成后逐项检查原来有效的人员照片与阅读入口。

## 6. 实际打开并完成交付

按内容选择字体、布局和色彩，可以测试浅色学术阅读、中性黑底图解或其他独立方案。先在有代表性的论文段落验证信息层次、原图可读性和交互，再扩展到本次范围。

在实际浏览器中打开交付入口，检查人物身份与图片、关键图表、展开内容、原图定位、动画控制和来源链接。将单文件独立复制到另一目录或设备后离线打开，确认原图、字体、脚本和内容仍可用；检查不同屏幕宽度与键盘操作，修复发现的问题。

### 构建后的加载与滚动性能

每次构建或内容增补后，将流畅度作为交付检查的一部分，先做代表性实测，有问题再深入定位：

- **实际阅读：** 打开最终交付入口，观察首次加载，在图、动画和视频较多的长段落连续上下滚动，并试展开／收起、章节跳转、搜索和原图放大。按实际交付范围检查本地包与线上版，区分冷加载与缓存后的表现。
- **定位开销：** 出现明显卡顿时，结合浏览器性能或网络记录区分脚本、布局、绘制、资源解码、媒体和网络开销；页面字节数与滚动流畅度分别判断，按定位结果选择修改。
- **控制资源加载：** 图片按展示尺寸优化、预留宽高并保留可读的原图入口；首屏关键内容及时加载，非首屏重资源按需加载。视频先呈现封面与播放入口，点击后才创建播放器，收起或关闭后释放。单文件保留完整内嵌资源，重图按需解码；在线版可用相对资源懒加载。优化保留必要论文大图与细节，分别观察下载体积、解码和滚动开销。
- **管理持续工作：** 滚动与窗口变化时合并必要更新，减少重复全页扫描和交错布局读写；按动画帧批量更新或按需节流。离屏、折叠及后台动画／媒体暂停或不启动，返回时遵循用户的暂停与播放状态。
- **复测与记录：** 优化后在相同条件下复测，核对搜索、锚点、原图细节及离线阅读仍可用。记录设备／浏览器、测试入口、实际观察与测量、修复结果及剩余限制；结构检查、资源压缩结果和流畅度实测分别报告，无法实测的部分据实说明。

### 内容与交付核查

对照正文、补充小节及表内方法清单，逐项检查实际使用／学习的信息、更新对象、行动用途与应用场景的覆盖；抽查像素、点云、潜表示等是否沿用真实定义，物性／规律解释是否有相应证据，以及显式／隐式、训练／冻结／逐场景优化和实验范围的区分。确认主文简答、展开细节和跨模型对照一致，未把控制基线或评测工具列作新模型。

抽查作者关键词／Index Terms与扩展检索词的标识、定义出处和语境，检查关键词索引、正文、方法及资源之间的搜索与双向跳转。

检查数据集专栏与论文实验的双向跳转、锚点唯一性、版本和指标说明；确认领域补充标识、榜单日期与在线依赖清楚可见。

交付 HTML、资源、可修改源码和必要的使用说明。若某项功能依赖本地服务，提供直接可用的启动入口，并在说明中写清用途。
