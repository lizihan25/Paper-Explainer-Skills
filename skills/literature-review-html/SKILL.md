# Literature Review HTML

围绕用户想理解或判断的问题，把文献组织成能学习、比较和继续研究的专题综述。沿用本次主题、受众、时间范围和交付要求；这份 skill 中的个人默认可以被当前要求替换。

## 选择工作指令

- [通用精炼 prompt](prompts/concise.md)：默认读取。可独立复制，保留模型在分类、叙事和视觉上的设计空间。
- [精细指导 prompt](prompts/guided.md)：需要明确检索、精读、综合和页面制作的衔接时读取。内容完整，可独立使用。

检索、归纳和 HTML 属于同一任务。既有库先读索引与研究状态，复用已读材料；更新只查影响本次结论的新证据和缺口。资料、术语与关系以 Markdown 为维护真源，HTML 从它派生。

## 本机执行

在用户指定目录工作；已有任务沿用其产物目录与台账，未指定时选本项目内的独立目录并说明。输入、输出、构建器和素材路径由当前环境确定，交付资源用相对路径。优先复用可运行的浏览器、PDF 和 HTML 工具。

需要原图、实验演示或人物照片时读取同目录的 [paper-assets](../paper-assets/SKILL.md)；制作页面、修复配图和交互时读取 [paper-reading-html](../paper-reading-html/SKILL.md)。未安装这些技能时，直接按所选 prompt 的素材与页面要求完成。若安装了 `hypo-exp`，写作或改稿时应用对应操作；表达原则也已包含在两份 prompt 中。

尤其在入门时，将原论文检索与优秀综述、领域专家的文献分享／专题报告／阅读清单、高质量大学公开课程并行推进。借助这些入口建立术语、分类、先修知识和代表论文线索；按主题匹配、讲者或课程背景、覆盖年代及参考文献可追溯性选择，多源对照并补查近期方向。关键论据回到原论文，教学顺序与真实研究承接分别组织；具体筛选与来源记录见所选 prompt。

同步检索各主题的重要数据集、测试集、评测基准和榜单，按主题设专栏，解释测什么、如何评测与使用局限。专栏和论文按实际训练／验证／测试用途双向跳转；选文未使用的重要资源作为领域补充介绍。版本、划分、指标、协议和动态榜单日期的记录要求见所选 prompt。

先做检索边界与问题分类，再精读支撑重要判断的原文，组织研究发展、教学先修与跨论文比较。原图是机制讲解的主要依据；动画用于显现信息变化，能暂停、重播并返回原图位置。作者身份、照片、年份和研究组与论文就近呈现。

交付可阅读的 Markdown、HTML、可分发资源和最小重建说明；需要迁移时打包。实际打开页面检查人物照片、原图定位、来源、交互、窄屏和离线阅读。多阶段任务保留覆盖状态、未决结论及下一步；实际工具无法完成的检查据实记录。
