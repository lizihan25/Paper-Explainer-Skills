# 文献综述与 HTML：通用精炼 prompt

围绕我给出的主题、论文或研究问题，完成检索、精读、跨论文归纳和 HTML 学习资料。沿用已有受众、用途、时间范围与资源约束；缺少非关键参数时作合理选择并继续。以下是个人默认，当前要求优先。

**逐模型追踪实际信息与应用。** 逐一解释所有实质介绍的模型／方法，包括补充小节与表内方法：实际用了什么信息（如像素／图像特征、点云／几何、潜表示、语言语义、观测或动作历史），学习或辨识什么及显式输出／隐表示／预测／策略等形式，哪些部分在本文训练、冻结调用或逐场景优化，怎样影响后续行动，以及主要应用场景与实际验证的对象、任务、真实／仿真及泛化范围。按论文真实定义说明信息，不必硬套物理信息；有依据时再列物理观测、人工先验、结构／损失约束与模拟条件。正文精炼，细节可展开，跨模型对照并互链；字段随方法调整，不强制长模板或互斥分类。课程、控制基线、传感器与评测工具按自身类型介绍。关键判断附来源，区分作者主张、实验支持、讲解者解释与未验证的泛化。将潜表示解释为质量／摩擦等物性需相应解码、探针实验等明确证据；规律学习、物性恢复与任务成功分别评估。语义常识与经标定的物性估计、权重学习与当前状态更新也分别说明。

**研究从问题开始。** 明确要理解或判断什么、哪些内容纳入、检索截至何时。尤其入门时，与原论文检索并行，优先找优秀综述、领域专家的文献分享／专题报告／阅读清单和高质量大学公开课程，借其分类、术语与参考文献建立候选和学习路线。查看相关内容，比较主题匹配、讲者或课程背景、覆盖范围与年代、所需先修及原文可追溯性；名气和校名作为发现线索。记录所用章节、讲次或时间点，交叉比较不同入口并补查近期方向。沿代表论文追踪前后引用、关键团队的系列工作、并存路线及反例，关键事实回到论文正文、附录、正式论文库或作者材料。用 DOI、arXiv 与题名核对去重，区分预印本、正式发表和修订版本。保存实际检索日期、渠道、检索式、筛选理由和阅读范围；规模由问题覆盖与证据决定，不凑篇数。检索范围与访问缺口决定综述的适用范围。

**关键词与定义也要建立索引。** 分别按原文保存对应版本的作者 Keywords 与 Index Terms，注明来源位置；未列字段与未能核实分开记录。另列研究者扩展的领域检索词，整理中英名、缩写和别名，区分同义、上下位与邻近但不同的概念。核心概念给出有来源的定义及本文语境，定义有差异时按来源并列；用词表帮助检索和理解，支持搜索、就近解释，并与论文、方法、数据集及资源双向关联。

**近期项目补充论文的时效缺口。** 对尚未形成论文的近期进展，可选内容完整的官方项目／GitHub 仓库作为项目材料，记录查询日期、release／commit、公开内容与实验／演示证据；论文结论、项目宣称、有复现材料与实际复现分别表述。热度用于发现候选，入选依据是其与研究问题的关系及可检查的内容。

**数据集与评测也是检索对象。** 按研究主题检索重要数据集、测试集、benchmark 和官方榜单，以原始论文、官方文档和实际采用情况说明入选理由；选文未使用但领域重要的资源也可列为“领域补充”。为各主题设置数据集与评测专栏，介绍任务、数据内容与代表样例、规模和采集方式、真实／仿真属性、版本、训练／验证／测试划分、指标含义及方向、评测协议、获取与许可、适用范围和局限。区分数据资源、测试划分、评测协议与动态榜单；榜单注明赛道、设置和查询日期，排名或分数只在相同协议与条件下比较。论文中的数据集名称链接到专栏，专栏返回关联论文与实验位置，并注明预训练、训练、验证、测试或仅讨论的实际关系；自建数据与公开数据分开记录，未使用的资源保持为领域补充。保留稳定 ID、原始来源与无法查明的字段，无正式榜单时据实说明。

**归纳要解释发展与取舍。** 选出真正值得深入的论文，补齐必要前置知识。沿具体输入说明信息怎样经过各模块变化并产生输出，分清训练和推理；把核心创新拆开讲清，与最近似基线比较，再用实验设计、条件、指标、消融和失败情况检验作者的解释。区分作者主张、原文证据与自己的评价，重要结论就近链接到相应章节、图表或补充材料。跨论文比较先对齐任务、数据和评测条件，保留不可直接比较的部分。

**模型的规模与复现条件也要讲清。** 核查模型规模、资源与复现条件：分别说明底座、视觉编码器和新增模块，总参数量与实际可训练参数；训练区分底座预训练、本文微调／从头训练及逐场景优化，记录已报告的GPU型号／张数、实测峰值显存（若报告）、时长或GPU小时、步数／epoch与batch。推理单列硬件、精度、输入尺寸／点数、batch、延迟或频率，区分模型前向、规划／重建、网络调用与端到端耗时。开源逐项检查代码、权重、数据、训练／评测脚本和环境，附官方入口及各自许可，区分实际可下载、仅承诺发布、部分发布与闭源API依赖。优先查原文、附录、作者仓库和模型卡；关键数字保留来源与版本日期。未报告、供应商未披露和未核实分别标明；自行计数／估算与作者报告分开，参数量或权重大小不直接代替运行显存，也不据此保证本机性能。在论文条目附近呈现，并与资源对照索引双向链接。

**专题资源先就地查看。** 正文的数据／评测专题及模型资源专题入口默认先打开按需浮窗，完整展示主题卡片、来源与论文回链；关闭恢复正文位置和焦点，另设可选的总表主题定位。保留常规链接供无脚本回退及修饰键点击，长内容独立滚动，窄屏可读；只准备当前主题内容，关闭清理临时内容与监听。

**让多篇论文形成关系。** 用问题、思想和证据组织正文，说明路线为什么分支、各自解决什么、为何又能结合。研究发展图标明实际承接或引用关系，教学路线单列概念先修与快读/深读顺序；发表先后、主题相似或课程讲授顺序不等于继承。推荐综述、分享和课程时说明分类视角、覆盖年代、适合读者及遗漏。需要服务项目选题时，再给有基线、实验条件和继续/停止依据的候选路线，保留尚待决定的部分。

**作者卡逐篇可达。** 尽可能为每篇纳入讲解或论文库的论文设置紧凑作者卡，普通点击在按需浮窗查看作者署名、第一作者／共同贡献、通讯作者及发表时机构／研究组；用原文、作者与机构官方资料核对，当前任职另列并标日期。通讯与贡献身份按明确资料标注，不从末位署名推断；仅确认部分信息时列明具体缺项，人物关系附依据。复用真实头像并保留来源和许可，缺照片时仍显示姓名与机构。逐篇核对作者入口覆盖，正文、论文库与人物总表双向关联；浮窗保留来源和可选总表入口，关闭恢复位置、焦点与展开状态，保留常规 href 回退。只准备当前资料，关闭释放临时内容与监听，避免增加滚动负担。

**素材需要寻找和选择。** 从论文、附录、项目页、作者代码与演示中选完整架构图、局部示意、输入输出和真实实验对照；从作者或机构页面核对人物照片。实际查看候选，在讲解尺寸下比较解释价值、版本与条件匹配、可读性和视觉焦点。记录出处、图号或视频片段、裁切方式和使用条件。原图在正文中占有足够面积，用中文导读解释看图顺序；动态机制适合时再补教学动画。重绘保留结构含义并标明教学示意，素材能访问与能再分发分别判断。

**HTML 同时方便快读与深读。** 默认中文，保留英文题名及术语；首屏简洁呈现核心问题、主要认识和阅读入口，完整机制、公式与实验证据可深入展开。正文和主图占主要面积，目录与路线导航紧凑。重点论文介绍全名、发表年份与场所、发表时的研究组和关键作者真实照片，方便记住谁做了什么。照片缺失时仍显示姓名、组别和原始主页。原图支持放大、局部定位和返回全图；讲解步骤对应平滑移动的定位框，保持位置上下文。动画可暂停、重播、分步查看。按内容选择图谱、对照表、筛选或搜索，避免把页面做成只有摘要卡片的资料柜。

逐篇核查原文、附录及补充材料的总览图／Workflow覆盖；已有可用总览图时引入并导读，缺少或不足以解释技术关键时，依据方法、图注与实验材料补教学流程图，明确标注重绘及来源。让输入→关键表示／模块→输出／执行可追踪，区分训练／部署、并行支路、监督与数据流，突出创新。保留必要原图，将补图接入完整Workflow对照；按内容选用清晰、可离线读取的SVG／HTML等形式，支持缩放与宽窄屏阅读，按需加载。

**原图导读要能展开到完整流程。** 原图保留简短导读，并提供可展开的完整Workflow。先说明全图解决什么、从哪里开始看、图例与关键符号；再按原图真实区域和标签，逐步解释每步收到什么、怎样处理、传出什么，以及分支为什么并行、在哪里汇合、回路何时更新。用一个明确标作教学示例的输入串起全过程，分清训练与部署、监督箭头与数据流、模型预测与规划／控制执行。术语就近解释，重点说清最易看错的连接与条件；细节回查论文方法和图注，图中未画出的操作明确说明来源，保留版本与来源定位。展开后仍能方便放大对照原图；详解的深度由理解需要决定。

**放大图时同时读完整Workflow。** 默认采用分栏图文对照（A）：图支持缩放、拖动与返回全图，导读独立滚动，图文比例可调，窄屏上下排列；关闭后恢复原阅读位置、触发点焦点和原有展开状态。另按图记住缩放、平移、图文比例、导读滚动位置和当前步骤，重开同图时恢复。重点架构图可再按解释价值增加步骤平滑定位（C），逐步核对所用原图版本、标签与实际区域，缩放或调整布局后定位仍准确。完整Workflow始终可读，允许跳步与自由浏览全图。由查看器接管图本体拖动，禁用原生图片拖出和意外选中；手动拖动／缩放时暂停自动定位和过渡，提供清楚的手动／跟随或视图锁定控制，锁定只限制自动变化。原图在正文和对照视图直接显示，外链用于追溯；性能优化保留必要原图与清晰细节，教学示意只补充，不能靠删图、替图或强制跳转／另存来减负。按需读取和解码当前图与导读，在打开、缩放、拖动、调整比例或切换步骤期间合并更新，静止和关闭时停止持续更新；实际验证图文对照、状态恢复、定位与流畅度，保留来源及素材许可。

**加载与滚动也要验收。** 把首屏加载与长页滚动流畅度纳入每次构建／增补后的验收：实际打开最终入口，在图、动画与视频密集的代表段落连续滚动、展开和跳转，发现卡顿先定位再优化、复测。图片按展示需要压缩并预留尺寸，首屏关键内容及时加载，其余重资源按需加载；视频点击才创建播放器，收起释放，离屏或后台暂停媒体与动画。滚动更新合并处理，减少重复DOM扫描及交错的布局读写；完整单文件按需解码内嵌图片，在线版可用相对资源懒加载；资源目录／ZIP为可选补充。保留搜索、锚点、全部必要原图的细节和离线能力。记录浏览器、环境与实际检查／测量结果，区分结构检查和流畅度实测；未实测的部分说明限制。

**源码可维护，成品可打开。** Markdown 保存内容、引用和关系，HTML 从它生成。默认交付可独立转发、离线打开的完整单文件HTML，内嵌必要本地原图、照片、样式和脚本；在线版可用相对资源按需加载并保留完整单文件下载，资源目录／ZIP为可选补充。在线材料保留来源、图注和阅读回退。更新时保留有效人物照片、来源与交互。长任务保存研究状态、覆盖缺口、待核查判断和下一步，接续时先读已有记录。使用分工时记录实际阅读与复核范围，不用模型角色名代替真实调用。

自然、具体地解释事实与关系，保留必要深度；删除空泛铺垫、虚构对立、制作自证和无内容的口号。表达遵循 Hypo-Expression；有相应 skill 时使用其写作或改稿操作。

完成后核查核心结论与图，实际在浏览器检查人物照片、图谱/筛选、原图放大、动画控制、来源、键盘与窄屏阅读，并将单文件独立复制到另一目录或设备后断网检查原图与交互。交付主要认识、推荐先读材料及理由、Markdown/HTML/资源入口和影响结论的剩余缺口；研究过程与验证记录保留在制作文件中。
