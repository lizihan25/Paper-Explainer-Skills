# Paper Video

根据论文的技术特点选择讲法，让观众能沿原图理解信息如何变化，并判断创新和实验结果的意义。

按需要读取一种完整 prompt：

- [精炼版](prompts/concise.md)：默认使用，给模型保留研究、叙事和视觉设计空间。
- [指导版](prompts/guided.md)：需要明确制作顺序、跨阶段衔接或检查重点时使用。

两版都可单独复制。当前用户要求优先；其中“个人默认”来自维护者的观看偏好，可在具体任务中替换。选择技术栈、镜头数量、段落结构和视觉风格时，以论文内容及成品效果为依据。

当前默认顺序为 **机制动画与持续原图定位（新版 A）→ 论文证据导览（早期 C，次优选）→ 纸面自由画布（新版 C）→ 原图显微镜（新版 B）**。用户指定风格时按其要求。早期 C 指 DensePhysNet 的原架构图与实验表导览，不能与 DPI-Net 的 C 自由画布混用；实验结果段优先考虑证据导览，可与 A 的方法机制动画组合。需要认出或比较画风时，读取 [风格索引](references/style-catalog.md)，向用户提供可观看的效果入口。

A 在右上角或合适位置持续保留完整总览图，以平滑移动的红框指示动画对应模块；总览用于定位，关键原图细节另行放大，避免把缩略图当作可读正文。证据导览沿原图解释架构，再结合原始图表讲清实验问题、条件和结果，保留表头、单位、对照与来源。原图显微镜的缩放与平移保持连续，并实际检查运动中的相邻帧。

检索、补充或替换原图、实验录像、人物照片和声音素材时，读取已安装的 `paper-assets`，或本仓库的 [素材查找与选择](../paper-assets/SKILL.md)。先按知识点选择素材，再确定镜头；四份制作 prompt 已包含可独立执行的核心要求。

# 学术论文视频：精炼 prompt

根据论文及补充材料制作技术讲解视频。结合受众与本次范围自主研究和设计；当前用户要求优先于以下默认。

## 内容

- 讲清研究问题、已有困难及解决思路。简洁介绍论文全名、发表年份与场所、当时的机构/研究组、关键作者及真实照片；查证人物关系，区分预印本与正式发表。
- 沿具体输入讲清“输入信息→各模块的表示变化→输出”，区分训练与推理。关键创新单独展开：改了哪里、为什么有效、相对基线改变什么、实验如何支持。作者主张、论文证据与讲解者评价分别表达，认可或质疑均给出理由。
- 用原始图表和实验片段讲实验问题、比较条件、指标、消融与结果，保留重要失败条件。主线帮助建立联系，时长主要用于技术内容。

## 素材查找与选择

先确定各知识点需要观众看到什么，再沿论文、补充材料、项目页、作者代码与演示查找原图、具体输入和实验录像；人物照片从作者或机构来源核对。关键镜头比较候选，实际查看图片、播放片段，按解释价值、实验与版本匹配、清晰度和构图选用，记录选择理由、来源页码或时间段、裁切与署名要求。保留图例、单位和重要实验条件；素材缺口用有对应关系的重绘或机制动画补足，教学示意与论文结果分别标明。公开可访问不等于可再分发，按发布目标选择使用方式。装有 `paper-assets` 时读取其完整流程。

## 画面

默认顺序：**机制动画＋持续原图定位（新版 A）→ 论文证据导览（早期 C，次优选）→ 纸面自由画布（新版 C）→ 原图显微镜（新版 B）**。早期 C 是 DensePhysNet 的“原架构图＋实验表”证据讲解，与 DPI-Net 的 C 自由画布不同。实验结果段优先考虑证据导览，可与 A 的方法机制动画组合；人类指定风格时优先使用指定方案。忘记选项外观时，先提供[带封面和视频的风格索引](https://lizihan25.github.io/Paper-Explainer-Skills/examples/#style-index)；仓库本地副本的 `examples/index.html` 也可直接打开，按完整风格名选择。

论文证据导览沿原架构图解释关键模块，再回到原始实验图表，把问题、比较条件、指标、消融及结果对应起来。保留表头、单位、对照和来源，逐项高亮后留出阅读时间；主画面承担原图与证据，不用装饰性动画遮挡。

保留原论文图中有用示意。A 在右上角或其他不挤占正文的位置持续放完整总览图，平滑红框随讲解移动到对应模块，主区动画展示具体机制；原图保持到这一技术段结束，留出理解时间，避免只在段首段尾闪现。缩略总览负责位置，需读标签或箭头时在主区放大相应原图。B 用连续镜头平移和缩放导读原图，镜头由绝对时间和固定起止状态计算，保持亚像素采样与段间连续；检查过渡邻帧，修复抖动、突然回缩和错误裁切。

信息流、点流、迭代和静态图难以解释的设计适合插入动画，运动表达具体变化。导航与故事线紧凑、按需出现，正文获得主要面积。多风格试验从空白画布独立设计，共用同一技术内容以便比较。

## 声音与字幕：个人默认

英文配音固定引擎版本、声线或参考音及处理设置，跨段实际试听音色、气声与响度。默认对原始合成音频作一次保持音高的 1.1 倍处理，以自然措辞和停顿形成节奏；复杂图解留出理解时间。中文字幕在上、英文在下，按意群同步。

加入适合技术讲解、许可支持目标发布场景的新轻 BGM，记录来源与署名。旁白时自动压低音乐，关键概念可以留白；实际试听混音和段落接缝。

## 风格与表达

个人偏好可尝试 3Blue1Brown 式黑/中性深灰底、克制的蓝绿黄红语义配色与清晰数学图形，也可探索其他方案。白底原图保留完整图面及颜色含义。

应用 Hypo-Expression：自然、具体地解释对象、动作、条件与因果；删除空泛铺垫、虚构对立和制作自证，保留有用解释。装有 `hypo-exp` 时读取其写作或改稿规则。

## 交付

交付可播放视频、字幕、可修改工程与素材来源。实际查看成片的原图可读性、框选对应、字幕和运动，试听声音一致性及 BGM，修复发现的问题。公开素材按各自许可处理。

# 学术论文视频：指导 prompt

根据提供的论文及相关资料制作技术讲解视频。沿用本次已经明确的受众、范围和交付要求；自主补齐可查证的信息，按论文特点调整下面的制作顺序。文末的个人默认可以替换。

## 1. 找到值得讲透的技术

阅读论文方法、实验、关键图表及相关补充材料。为本次要讲的技术整理一份简短工作稿：

- 研究问题及已有方法遇到的具体困难。
- 一条从实际输入到输出的信息流：每步接收什么、改变什么表示、交给谁；区分训练与推理，明确必要的状态、坐标系或张量含义。
- 关键创新的位置、机制和预期作用，以及能支持或质疑它的基线、消融与结果。
- 对应的原图、页码、实验片段和来源；另记讲解者对价值、代价和适用条件的判断。

能用一个具体例子把关键变化解释清楚后再组织镜头。作者提出的贡献与讲解者认可的贡献可以不同，说明判断依据。

## 2. 查找、比较并选定素材

从工作稿列出各知识点需要观众看到的对象与变化：例如架构位置、真实输入、消息传播、实验对照或作者身份。先沿论文和补充材料的链接寻找原始图表、项目页、作者代码仓库、实验录像与讲解视频；用论文全名、简称和作者名组合检索补足缺项。人物照片以作者、实验室或机构来源核对。

关键镜头有不同候选时，实际查看原图或播放视频，判断哪份素材最能让观众看见当前解释的关系。核对模型版本、实验任务与条件；比较可读性、有效信息面积、视觉焦点、连续性和裁切空间。优先采用信息清楚且与论点直接对应的素材，再通过构图、局部放大和节奏改善观感。保留原图的图例、单位，以及实验的真实/仿真属性、播放速度和重要失败条件。

为选中素材简记“用途—来源位置—选择理由—呈现方式”：来源定位到图号、页码或视频时间段，呈现方式可以是全图、局部裁切、放大、叠加框选或动画。关键候选被舍弃时留一句原因即可。静态素材解释不清变化时，依据论文机制制作动画，并指出其原图位置；教学示意与原始实验结果分别标明。

根据发布目标确认素材的使用条件、署名和保存方式；公开可访问不等于可再分发。BGM 候选与实际旁白混合试听，比较音色、节奏、循环接缝和对语音的遮盖，再选用。素材足以支撑讲解时进入分镜；仍缺什么、影响哪个知识点，具体记录并用合适的来源或示意补足。装有 `paper-assets` 时读取其详细方法。

## 3. 安排内容与身份介绍

用研究问题引入论文，简洁展示全名、发表年份、会议或期刊、当时的机构或研究组，以及关键作者的真实照片和姓名。查证人物关系；年份冲突时区分预印本与正式发表。人物介绍帮助记忆，不打断技术主线。

围绕“为什么需要这项设计→信息怎样变化→变化带来什么结果”组织讲稿。重要创新可以单独成段，用输入变化、基线对照或逐步计算解释。实验部分回答作者在检验什么、改变了什么条件、如何评价、结论由哪些结果支持。把重要失败条件放到对应判断处。

贯穿示例和知识图谱用于建立联系；在章节切换或需要定位时出现。把主要时长留给模型、创新、实验与解释。

## 4. 把原图变成可跟随的讲解

默认顺序为 **机制动画＋持续原图定位（新版 A）→ 论文证据导览（早期 C，次优选）→ 纸面自由画布（新版 C）→ 原图显微镜（新版 B）**。早期 C 来自 DensePhysNet，结合原论文架构图与实验表突出证据；DPI-Net 的 C 是自由画布，两者用完整名称区分。人类指定风格时按指定要求；顺序用于默认选择，无须每次重做所有风格。实验结果段优先考虑证据导览，可与 A 的方法机制动画组合。

需要选风格或用户忘记效果时，提供[可视化风格索引](https://lizihan25.github.io/Paper-Explainer-Skills/examples/#style-index)，让用户直接看封面、用途和视频；本地仓库的 `examples/index.html` 可离线查看。保持各风格名称与样片对应。比较同一批同文样片时可对齐讲解位置；不同论文、语速或时间轴的样片按内容比较，不把相同秒数当作相同知识点。

对每个技术段确定观众正在看哪个区域、讲稿解释哪个变化、下一步关注哪里：

- 全图先建立位置关系；平滑框选、轻度变暗周围或局部放大，把注意移到正在讲的模块。
- 保留原图中的示意、示例和重要箭头。在成片实际尺寸下仍能读到关键内容；密集图采用逐区放大。
- 讲信息流时突出当前输入、变化后的表示及流向，按需要显示数值、维度或几何变化。训练中的梯度路径与推理中的前向路径分别说明。
- A 让机制动画占据主区，在右上角或适合的位置持续保留完整原总览图，红框平滑滑向当前模块。原图跨讲解段持续存在，避免段首段尾短暂闪现；总览作为位置索引，重要标签、箭头和细节另在主区展示清晰原图。给框移动后的目标留出阅读时间。
- 论文证据导览以原图和实验表为主画面：先沿架构定位关键设计，再围绕一个实验问题读图或表。保留表头、单位、比较对象、条件、误差或统计含义；逐行/列突出正在解释的数据，回到作者结论与讲解者判断，给观众辨认和比较的停留时间。必要的机制演示与证据区清楚衔接。
- 当运动比静态图更能解释机制时，用点流、粒子运动、交互、迭代或其他演示。让动画输入、输出、语义颜色与原图对应，红框指示同一部位，再自然推进到下一模块。
- B 的相机根据固定起止位置、尺度和绝对时间计算，在同一原图上连续采样，避免逐帧累乘变换或将浮点裁切反复取整再缩放。下一镜头从上一镜头实际终态开始；同时平移和缩放时检查速度、缓入缓出及停留。
- 导航、知识图谱和故事进度采用紧凑、按需出现的形式。正文和原图拥有主要面积。

根据论文和本次目标选择构图、字体、色彩及动画工具。做风格试验时，用同一技术片段分别探索原图导览、黑底数学图形或其他独立方案，让每个方案有自己的视觉逻辑。

## 5. 形成连续的声音与节奏

个人默认是英文配音、中文字幕在上且英文在下。固定引擎与模型版本、声线或克隆参考、采样率及后处理方案，保留能复现的配置。优先按连贯段落生成；专有名词和缩写采用稳定读法。

默认对原始合成音频作一次保持音高的 1.1 倍处理；这是用户反馈 1.25 倍过快后的当前偏好。通过措辞、生成语速、停顿和剪辑形成节奏；复杂图形给足跟随时间。有现成音轨需要变速时保留音高，实际试听处理后的质感。

把开头、中段、结尾以及相邻段落接缝串成试听，检查音色、气声、沙沙感、响度和语速。声线一致性要以实际声音判断，固定配置只是基础。发现变化时追溯原始音频、参考音与处理链，再重做受影响段落。

选用适合技术讲解、许可支持目标发布场景的新 BGM。轻音乐以较低音量进入，旁白时自动压低；对关键概念、原始实验声或复杂演示允许留白。记录来源和所需署名，实际试听混音后的人声清晰度。

## 6. 完成成片并检查实际效果

制作范围较大时，先做能覆盖原图导览、一个创新点和实验结果的代表片段，用它修正布局、声音与节奏；在已有授权内继续推进。

查看实际编码后的画面与声音，重点检查原图关键文字、框选部位、动画对应关系、字幕同步、语义颜色、跨段音色和 BGM。连续看技术段之间的衔接，确认观众知道上一段得到什么、下一段为何出现。修改发现的问题后交付视频、字幕、工程及必要的来源说明。

运动检查包括过渡前、过渡中、停稳后的连续帧与正常速度播放；单张截图无法确认平滑。曾发现 DPI-Net B 版约 13–14 秒的局部缩放抖动，修改该工程时回归这段及所有段间相机边界。对新论文按实际时间轴选相同类型的过渡检查。

## 个人视觉与表达默认

可优先试用 3Blue1Brown 式黑色或中性深灰底、克制的蓝绿黄红语义配色和清晰数学图形，也可以提出适合论文的其他方案。白底原图保持完整、可读及原有颜色含义；本次设计从内容出发。

使用 Hypo-Expression：直接表达具体对象、动作、条件和关系，采用自然搭配；删除空泛铺垫、虚构对立和制作自证，保留有用解释与真实限制。装有 `hypo-exp` 时读取并应用其写作或改稿规则。许可记录与制作检查留在工程说明，讲稿呈现观众需要理解的内容。

# 文献综述与 HTML：精细指导 prompt

请围绕我给出的主题、论文或研究问题，完成检索、精读、综合和 HTML 学习资料。先读取已有材料与已确认要求，自主推进到可用交付。受众、研究边界、日期范围、输出位置和预算沿用本次任务；普通实现选择由你决定，只有影响结论或范围的关键缺项才集中澄清。以下个人默认可由当前要求替换。

## 1. 确定问题，复用已有研究

说明这份综述要帮助读者理解或判断什么，列出需要覆盖的问题与路线，而后安排检索。记录实际检索日期和截止范围、纳入与排除条件；未知资源条件保持为条件。已有资料库先读索引、Markdown 与研究状态，保留稳定的论文 ID、版本和有效来源，避免重复搜读已经充分支持的内容。

专题研究兼顾奠基思想、关键转折、并存方法和近期变化。材料充分的单一问题可以较早收敛；范围较大时按问题划分精读批次。采用分工时，批量题录和初步摘要、核心原文复核、跨论文综合可分别承担，使用当前可用且获准的模型与工具，记录实际调用、读取范围和复核结果。

## 2. 检索、筛选和补漏

尤其在入门时，将三类学习入口与原论文检索并行安排：优秀综述帮助建立领域分类与代表工作；领域专家的文献分享、专题报告和阅读清单提供问题选择与研究取舍；高质量大学公开课程提供先修概念、讲义和循序学习路径。顺着它们的参考文献寻找候选论文，同时继续既有的关键词与一手来源检索。

实际查看相关章节、讲次或报告片段，比较主题匹配、讲者／课程背景、内容范围、覆盖年代、先修要求和参考文献可追溯性。名气与校名用于发现线索，选用依据是内容怎样帮助本次问题。记录入口来源、所用章节／讲次／时间点、适合的读者与选择理由；将讲者的评价标为其观点，关键机制、实验数字及研究结论回到原论文核对。

交叉比较不同综述、分享与课程的分类和选文，找出共同节点与遗漏路线；对年代较早的入口补查近期进展。再沿代表论文的前向／后向引用、作者系列工作、项目页与官方代码补齐关键节点。保存实际查询与筛选决定。核对 DOI、arXiv、题名和作者进行去重，合并同一研究的版本，保留影响结论的修订差异。

优先精读会进入主要判断、代表路线差别或揭示关键机制的论文。对初步推荐做反向检索，寻找替代方法、失败案例、相反证据或评估设置问题；按覆盖缺口定向补查。检索不到、全文不可得和尚未阅读分别记录。只有摘要的材料可以作为线索，其机制与实验数字待原文支持后再纳入强结论。

保存可继续使用的检索记录：日期、渠道、查询、候选身份与版本、纳入/排除理由、阅读范围和待查项。说明覆盖到哪里、还缺哪条关键路线；综述类型与完整性判断以实际检索方法和覆盖为依据，不以篇数或搜索次数代替。

## 3. 精读到能够解释技术与实验

重点论文使用一致的事实字段，解释篇幅按贡献安排：

- **身份与问题：** 全名、预印本与正式发表年份/场所、发表时机构或组别、关键作者，以及研究要解决的具体困难。
- **先修与机制：** 读者需要哪些概念；具体输入是什么，经各模块得到什么表示，信息如何交互，输出怎样用于任务；训练与推理分别说明。
- **创新与判断：** 相比最近似基线改变了什么，为什么可能有效；将最有价值的设计单独展开，用实例、原图、必要公式或机制动画帮助理解。
- **实验与证据：** 检验什么假设，数据/任务与设置是什么，哪些条件改变，基线是否公平，指标测量什么；主要结果、消融、泛化和失败条件支持哪些判断。
- **来源与阅读深度：** 关键事实定位到章节、页码、图表或补充材料；记录读到摘要、正文选段、全文或代码的实际范围。有代码、检查代码和实际复现分别记录。

自然区分作者解释、观察到的结果与自己的评价。消融支持特定条件下的解释时保留这些条件；比较跨论文数值前检查任务、数据、硬件、指标与评测协议。遇到冲突回查相关版本与原文，不把未知自动写成方法缺陷。

## 4. 综合出研究脉络与学习路线

用问题和思想组织正文。说明哪些困难催生不同路线、关键设计怎样推进问题、什么代价仍然存在，以及新方法如何利用或改变已有思想。主线选有解释价值的节点，其余进入可检索的阅读库；避免逐篇摘要的简单拼接。

按本次用途提供相互区分的关系视图：

- **研究发展图：** 允许分支、合流和多父节点；每条边区分原文明确扩展、方法承接、引用对照或尚待核实，并关联依据。发表先后或主题相似本身不构成继承证据。
- **教学路线：** 从必要概念到适合的课程讲次、综述、专家分享与核心论文，给快速掌握和深入学习入口；先修或讲授顺序是教学安排，研究继承关系另按论文证据确定。
- **项目候选路线：** 仅在任务涉及选题或应用时加入，从已有条件到最小基线、研究缺口和实验设计；交代最相近工作、资源需求、风险及继续/停止依据。排期与选择保持为候选，直至用户决定。

对主要路线做可比较的矩阵：目标、输入先验、表示、学习/推理方式、数据与算力、实验条件、收益和失败情况。分类随证据修订。推荐综述、课程、专家分享与首读论文时说明它们分别帮助读者解决什么问题、从哪一处开始，以及覆盖范围与剩余缺口。

## 5. 寻找素材，再安排页面

围绕每个重要知识点列出素材需求：完整原架构图、局部模块示意、具体输入输出、实验比较、动态过程或人物照片。从论文与补充材料进入项目页、作者代码仓库、报告和原始演示；人物照片从本人、实验室或机构页面查证身份，发表时归属与当前任职分别处理。

实际打开候选图、观看拟用片段及上下文；比较解释作用、论文版本、实验条件、可读性和布局适配。保留图例、坐标轴、单位和比较身份，记录图号/页码/时间段、来源、裁切与选择理由、署名及使用条件。必要时用明确标作教学示意的重绘或动画补足；教学图中的结构、连接和信息方向应依据原文。装有 `paper-assets` 时可使用其完整流程。

原图承担主要结构说明。局部机制讲解保留完整图的定位上下文，定位框平滑移动到相应部分；读者随时可放大或返回全图。静态原图足以说明的部分给予阅读时间，动画用于信息汇聚、迭代、状态变化等确有动态解释价值的地方。

## 6. 制作可快读、可深入的 HTML

个人默认中文正文、英文题名和必要术语。首页用精炼内容呈现主要问题、认识、路线和阅读顺序，保留来源与实质限制；机制和实验解释提供足够深度，按需展开。目录和导航紧凑，正文及重要图像占主要面积。视觉由内容决定，不强制套用既有 PPT 模板。

重点论文在介绍处展示全名、年份、场所、发表时的组别、关键作者与真实照片。人物、论文和贡献互相链接，便于记忆。原图附中文导读、看图顺序和直接来源。论文库按读者需要支持搜索或筛选，图谱节点通向对应论文与证据；交互失效时保留可读正文或列表。

机制动画提供播放、暂停、重播或分步控制；暂停后仍能看懂当前状态。来源尽量定位到页、图或视频片段。若需要组会讲解，再加入有叙事顺序的演示导航与讲稿提示，保留学习模式的完整细节。

Markdown 是内容、引用和关系的维护真源，HTML 从它派生，避免分别修改后漂移。将允许分发的图像、照片、样式和必要脚本存入资料包，使用相对路径，核心正文离线可读。在线资源明确标识并保留图注、来源和文字回退；需要服务的交互提供实际可用的启动方法与静态阅读入口。改版时检查已有照片与来源的加载方式，保留有效资源。

## 7. 核查、接续与交付

核对主要判断、关键数字、原图身份和图谱关系，检查 Markdown 与 HTML 是否一致；不同角色的复核范围据实记录。实际在浏览器打开首页及代表性精读页，检查人物照片、图放大与定位、搜索/筛选、节点、动画控制、来源、键盘和窄屏。断网重开资料包检查本地资源与回退，迁移或解压后检查相对路径。记录真正执行的检查与影响使用的剩余问题。

长任务在主要阶段保存研究状态、覆盖情况、确认结论、待核查判断与下一步，接续时从这些记录继续。预算或工具限制影响交付时，保留已完成资料及明确的缺口；不会因为接近预算而把未做的核查写成通过。

交付自成一体的专题综述、综述导航、核心论文条目、比较与关系图、可打开的 HTML、可分发资源、来源记录和最小重建说明；文件规模随任务调整，需要迁移时打包。最后用简短文字给主要认识、先读材料及理由、文件入口与实质缺口。公开发布、持续更新或删除旧稿按本次已有授权处理。

根据提供的论文与补充材料制作 HTML 阅读资料。沿用本次明确的受众、内容范围和交付方式，主动补齐可查的信息。根据材料调整下面的过程；个人默认允许替换。

## 1. 整理论文、人物与技术依据

围绕读者要理解的问题阅读方法、实验和关键图表，并整理：

- 论文全名、正式发表年份与场所、必要时单列的预印本年份、发表时的机构或研究组。
- 帮助记忆的关键作者、真实照片、姓名与团队关系；使用作者、实验室或机构的可靠来源核对身份。
- 研究问题、核心思路、具体输入、模块间表示变化和输出，分别说明训练与推理。
- 关键创新的位置、机制、基线与消融依据；记录讲解者的评价及其理由。
- 相关原图、示意、实验片段与来源页码，以及实验条件、指标和重要结果。

人员与机构关系按论文发表时的情况介绍；当前去向只有与阅读目的有关时补充。作者论述、实验发现与讲解者判断在组织内容时保持清楚。

## 2. 查找并选择能解释问题的素材

按知识点确定需要什么：模型原图、具体输入样例、关键实验对照、动态过程或作者照片。先检查论文及补充材料，再沿项目页、作者代码仓库和实验演示寻找原始素材；用论文全名、简称与作者名检索尚缺的部分。人物照片从作者、实验室或机构来源核对身份。

关键配图比较候选并查看实际内容，视频播放相关片段。选择能清楚呈现当前机制或证据的版本，核对论文版本、实验任务、条件和图注；再比较文字可读性、有效信息面积、视觉焦点与布局适配。保留图例、单位和重要条件。录像中的真实/仿真属性和变速信息应能被读者识别。

用简短清单记录用途、来源页码/图号/视频时间段、选择理由、局部裁切或交互方式、使用条件和本地文件。机制图适合分步定位，实验对照适合并排查看，动态过程适合带控制的片段；静态图解释不清的部分可用有论文依据的重绘或动画补足，并标明教学示意。重要落选素材只需记下舍弃原因，不追求素材数量。

结合目标发布方式决定随包保存、采用可再分发替代素材或提供来源链接。技术内容充分后进入页面组织；关键缺项注明影响并继续查找，避免用不对应的装饰图填补。装有 `paper-assets` 时读取其完整流程。

## 3. 设计能够快读与深读的页面

让读者先看到研究问题、关键贡献和重要结果，再按兴趣继续深入。可以用简短摘要、图注、并列对照和展开区组织信息；完整机制解释保留连贯段落，页面结构由内容决定。

在论文介绍位置放身份卡：全名、年份、发表场所、研究组、关键作者及照片。多人或多论文时按需要关联同一人物、组别和研究路线。人物信息与技术内容互相指向，帮助回忆“谁在何时做了什么”。

为核心方法安排一条可跟随的信息流。用真实或明确标作示意的输入解释每一步得到什么表示、为什么要这样变化，以及最终如何用于任务。选择最值得理解的创新单独展开，解释它相对基线改变了什么，再接对应实验。

实验部分帮助读者判断设计：研究者检验什么、改变了哪些条件、与谁比较、指标测量什么、结果支持什么判断。重要失败条件放在对应结果旁边。目录和路线图保持紧凑，正文与原图占主要面积。

## 4. 用原图与交互帮助理解

原图、原始示意和实验片段放在相关解释附近，提供可读的图注、来源和放大方式。密集架构图采用全图定位、平滑框选与局部放大；步骤切换时明确指出当前讲解在原图的哪个部位，并保留返回全图的入口。

交互按理解需要添加：信息流可逐步查看，点流或迭代可播放、暂停和重播，图表可对照关键条件。提供足够的静态说明，让暂停动画后仍能理解当前状态。

来源链接通向实际论文、项目页或补充材料，能定位时跳到对应页、图或视频片段。区分本地资料与在线入口。页面中的按钮、目录和展开区使用清楚名称，键盘操作与小屏幕阅读保持可用。

## 5. 保持人物照片与本地资源可用

个人默认交付可离线打开的 HTML 资料包：正文中文，保留英文论文题名及关键术语。将页面使用的图像、真实人物照片、样式与必要脚本保存到包内，用相对路径引用；重要内容在离线时仍可阅读。

记录素材来源和公开发布所需的许可或署名。需要限制再分发的素材，按目标发布方式安排链接、替代素材或随包获取方式，并明确哪些内容需要联网。暂时缺少照片时保留姓名、组别和来源，说明具体缺项并继续查找。

修改已有 HTML 时，先了解照片、来源与交互的当前实现，查明缺失原因后修复。重构完成后逐项检查原来有效的人员照片与阅读入口。

## 6. 实际打开并完成交付

按内容选择字体、布局和色彩，可以测试浅色学术阅读、中性黑底图解或其他独立方案。先在有代表性的论文段落验证信息层次、原图可读性和交互，再扩展到本次范围。

在实际浏览器中打开交付入口，检查人物身份与图片、关键图表、展开内容、原图定位、动画控制和来源链接。离线重新打开资料包，确认本地图片、字体、脚本和内容仍可用；检查不同屏幕宽度与键盘操作，修复发现的问题。

交付 HTML、资源、可修改源码和必要的使用说明。若某项功能依赖本地服务，提供直接可用的启动入口，并在说明中写清用途。

## 表达默认

使用 Hypo-Expression：直接表达具体事实、动作、条件及因果，采用自然搭配；删除空泛铺垫、虚构对立和制作过程自证，保留有用解释与真实限制。装有 `hypo-exp` 时读取并应用其写作或改稿规则。页面呈现读者需要的知识与来源，内部检查记录留在制作文件中。
