# Paper Video

根据论文的技术特点选择讲法，让观众能沿原图理解信息如何变化，并判断创新和实验结果的意义。

按需要读取一种完整 prompt：

- [精炼版](prompts/concise.md)：默认使用，给模型保留研究、叙事和视觉设计空间。
- [指导版](prompts/guided.md)：需要明确制作顺序、跨阶段衔接或检查重点时使用。

两版都可单独复制。当前用户要求优先；其中“个人默认”来自维护者的观看偏好，可在具体任务中替换。选择技术栈、镜头数量、段落结构和视觉风格时，以论文内容及成品效果为依据。

当前风格优先级为 **A → C → B**：A 黑底数学剧场（机制动画＋持续原图定位）、C 自由画布（空间连续的研究路线）、B 原图显微镜（原图局部导览）。字母指本仓库 DPI-Net 三版样片，不指更早 DensePhysNet 样片。用户指定风格时按其要求。A 在右上角或合适位置持续保留完整总览图，以平滑移动的红框指示动画对应模块；总览用于定位，关键原图细节另行放大，避免把缩略图当作可读正文。B 的缩放与平移保持连续，并实际检查运动中的相邻帧。

检索、补充或替换原图、实验录像、人物照片和声音素材时，读取已安装的 `paper-assets`，或本仓库的 [素材查找与选择](../paper-assets/SKILL.md)。先按知识点选择素材，再确定镜头；四份制作 prompt 已包含可独立执行的核心要求。
