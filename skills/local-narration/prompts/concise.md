# 本机配音 prompt

使用我已有的本地环境生成配音，优先 Breeze-TTS-2，IndexTTS-2 用于指定的替代或同文对照。读取私有配置与环境说明：`--config` 优先，其次 `LOCAL_NARRATION_CONFIG`，最后 skill 内 `config/local.json`；新电脑从 `config/example.json` 填写路径，所有相对路径以配置文件目录为基准，也支持环境变量。先用 `--resolve-config` 解析，再用配置中的 Python 执行 `--check`。复用已有模型，不把个人绝对路径写进公共 prompt；有本地工具时实际执行，没有时输出可交给本地执行器的任务与命令。

默认英文、固定合成 F 声线、保持音高的 **1.1 倍**速度。F 的身份使用同一个参考 WAV 及完整转录固定，不逐句重新设计声线；1.25 倍已被我反馈为过快。按连贯段落生成，复杂内容留出停顿。展示原文与发音替换分别保存，避免把缩写读法改写进字幕。

默认同时交付配音与字幕。准备双语 JSON 讲稿，每条字幕含 `en`、`zh` 和 `paragraph`；同段连续生成，字幕按能读完的短意群切分。中文在上、英文在下，技术译名、符号、数字与单位保持准确。对齐实际变速后的音轨，输出双语 SRT、独立中英文 SRT 和 ASS 样式文件。检查同步、断句、字号、边距和遮挡，速度或剪辑改变后更新字幕。只有明确要求仅音频时才跳过。

采用无损 WAV、固定增益及峰值余量，保留原始音频。BGM 按任务另做。试听开头、中段、结尾及相邻段接缝，检查声音一致性、沙沙感、漏词、重复、截断和语速。ASR 用于核对内容和字幕时间，不代替听感判断。

遇到音质问题，用相同文本、参考和响度比较原始/处理后音频，每次只改变一个关键因素。调用随包 `scripts/narrate.py`，交付可播放旁白、原始 WAV、字幕、原文/发音文本、实际配置与必要检查结果。
