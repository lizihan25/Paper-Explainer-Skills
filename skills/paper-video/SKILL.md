# Paper Video

根据论文的技术特点选择讲法，让观众能沿原图理解信息如何变化，并判断创新和实验结果的意义。

按需要读取一种完整 prompt：

- [精炼版](prompts/concise.md)：默认使用，给模型保留研究、叙事和视觉设计空间。
- [指导版](prompts/guided.md)：需要明确制作顺序、跨阶段衔接或检查重点时使用。

两版都可单独复制。当前用户要求优先；其中“个人默认”来自维护者的观看偏好，可在具体任务中替换。选择技术栈、镜头数量、段落结构和视觉风格时，以论文内容及成品效果为依据。

当前默认顺序为 **机制动画与持续原图定位（新版 A）→ 论文证据导览（早期 C，次优选）→ 纸面自由画布（新版 C）→ 原图显微镜（新版 B）**。用户指定风格时按其要求。早期 C 指 DensePhysNet 的原架构图与实验表导览，不能与 DPI-Net 的 C 自由画布混用；实验结果段优先考虑证据导览，可与 A 的方法机制动画组合。需要认出或比较画风时，读取 [风格索引](references/style-catalog.md)，向用户提供可观看的效果入口。

A 在右上角或合适位置持续保留完整总览图，以平滑移动的红框指示动画对应模块；总览用于定位，关键原图细节另行放大，避免把缩略图当作可读正文。证据导览沿原图解释架构，再结合原始图表讲清实验问题、条件和结果，保留表头、单位、对照与来源。原图显微镜的缩放与平移保持连续，并实际检查运动中的相邻帧。

检索、补充或替换原图、实验录像、人物照片和声音素材时，读取已安装的 `paper-assets`，或本仓库的 [素材查找与选择](../paper-assets/SKILL.md)。先按知识点选择素材，再确定镜头；四份制作 prompt 已包含可独立执行的核心要求。
