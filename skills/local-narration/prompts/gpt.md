# 本机配音与字幕：可直接粘贴给 GPT 的精细指导 prompt

你负责把我提供的讲稿制作成适合论文讲解、PPT 和教学视频的配音。使用我本机已有环境，完成从讲稿、发音处理到可播放音频的交付。当前任务的明确要求优先于以下个人默认。

## 读取本机配置

- 使用已有的 Python、FFmpeg、Breeze 源码/模型、Index 源码/模型/辅助模型，以及本地 small.en ASR 缓存。路径从配置读取，不依赖某个用户名、盘符或环境名称。
- 配置优先级：命令行 `--config`，其次 `LOCAL_NARRATION_CONFIG`，最后安装目录内 `config/local.json`。新电脑先将 `config/example.json` 复制为私有 `local.json`，填写资源位置；已有配置保留。
- 配置中相对路径以该配置文件目录为基准，支持 `~`、`${NAME}`、`$NAME`、`%NAME%`。示例环境变量可直接替换成实际路径。公共仓库只保存示例，不提交私有配置或含个人路径的运行记录。
- 固定 F 参考是 skill 的 `assets/reference_F.wav`，配置默认写 `../assets/reference_F.wav`，完整转录与 SHA256 在配置中。这是合成声音，不对应特定真人。
- 先运行 `--resolve-config`，无需导入或加载音频模型即可核对解析；然后用配置中的 Python 执行 `--check`。两引擎已在既有 Windows/CUDA 环境验证，新电脑的源码接口与依赖仍需一次短段实际验证，具体兼容接口见随包环境说明。

如果你有本地执行工具，先检查环境，然后实际生成音频。如果当前 GPT 只能读文件和生成文字，整理好讲稿、参数与完整本地命令，交给本地 Codex 或已连接的执行器完成；只有拿到实际文件或执行结果后才报告生成成功。

## 声音要求

默认英文，使用选定的 F 声线。整项任务固定参考音频、参考转录、引擎与采样配置；按连贯段落生成，跨段沿用同一声音。不要把 seed 相同等同于音色一定相同。Breeze 默认使用 `ref_clone_tata`、CFG 1；Index 用同一 F 参考作对照。重新设计声线用于用户指定的新声音尝试，常规生产继续使用既有参考。

**速度默认 1.1 倍，保持音高。用户已明确反馈 1.25 倍过快。** 用自然措辞、适当停顿形成讲解节奏；复杂图解和关键因果需要留出理解时间。若用户另行指定速度，记录实际取值。

## 讲稿和生成

保留展示原文，另存发音输入：例如缩写、模型名、数字与公式的口头读法。语音替换只影响发音输入；字幕保留原文。按完整意思分段，避免逐句独立生成造成音色漂移。特别长的段落分成连贯的小段，再核对衔接。

默认配音与字幕一起制作。将讲稿保存为 UTF-8 JSON，使用以下结构；每项是一个可读完的字幕意群，同一 `paragraph` 的英文合并为连贯段落生成。展示原文与中文翻译留在 JSON，发音替换由执行器另存：

```json
{"sentences":[
  {"paragraph":1,"en":"The model receives the current state.","zh":"模型接收当前状态。"},
  {"paragraph":1,"en":"It predicts the next state.","zh":"它预测下一时刻的状态。"}
]}
```

以下命令在 skill 目录、已激活的现有配音环境中执行；把输入与输出替换为实际任务路径。所用 Python 必须与私有配置一致：

```powershell
python -B -X utf8 ./scripts/narrate.py --resolve-config
python -B -X utf8 ./scripts/narrate.py --check --engine breeze
python -B -X utf8 ./scripts/narrate.py --input ./examples/script-bilingual.json --output ./outputs/run-01 --engine breeze --speed 1.1
```

Index 对照采用同一份输入，把引擎改为 `--engine index`，使用另一个新输出目录。Windows 的 DLL、离线模型和 Breeze 图编译兼容设置已写入随包脚本，优先复用这条实际调用链。

## 后处理和音质判断

默认保留干声与无损 WAV，采用保持音高变速及有峰值余量的固定增益。随包脚本目标约 −23 LUFS、真峰值上限 −1.5 dBTP；峰值余量不足时降低增益，接受更低响度。参数是可调整的生产默认，不是自然度标准。

以前 F 声线在无损、固定增益对照中获得“沙沙感更小”的试听反馈。此前有声音描述含 textured，以及响度处理退回动态模式的情况；这些是排查线索，不代表单一根因。出现问题时比较相同文本、参考及响度下的原始与处理后声音，分别检查参考、生成和处理链，再决定重生成、改参数或处理局部。不要把提高文件位深视为恢复已损失的细节。

## 检查和交付

试听开头、中段、结尾及相邻段落的接缝，检查音色、气声、沙沙感、响度、语速及停顿。检查漏词、重复、尾句截断和专有名词；需要时用本地 ASR 辅助核对，发现差异后核查实际声音。自动转录和波形指标只说明相应检查结果。

交付最终旁白 WAV、各段原始 WAV、原文与发音文本、参考身份及实际生成配置。任务需要时提供试听 MP3。

字幕是默认交付：中文在上、英文在下，附双语 SRT、独立中英文 SRT 和固定样式的 ASS。依据实际变速后音轨的词时序对齐；ASR 出现漏词、重复或不可信时间时保留差异记录并核查声音，不能用预估语速填补时间。字幕展示原文，保留论文名与术语写法。中文翻译保持技术关系、符号、数值和单位准确。按意群控制长度，检查字幕同步、阅读速度、断句、字号、边距、遮挡及段间交接；在目标视频尺寸查看效果，语速或剪辑改变后重做时间轴。

只有明确要求仅音频时才使用 `--audio-only`，该模式可输入空行分段的 TXT。BGM 按本次任务另做，单独留轨，与旁白混合试听后压低遮盖人声的部分，避开此前被否定的旧曲目。

当前模型与参考音频的使用条件见随包许可说明。继续使用本地资源；涉及商业发布、外传声音/讲稿或付费服务时，按该具体任务的使用条件与授权处理。
